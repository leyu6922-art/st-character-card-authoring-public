# Public Core Sources

This candidate intentionally contains only newly authored, neutral public-readiness material and standard-library tooling selected for the Core boundary.

The following are explicitly excluded from the candidate export:

- novels and excerpts
- private character cards and production cases
- images and presets
- archived audits and maintenance backups
- private paths, local notes, and sibling skills
- material with unresolved redistribution provenance

This file is a scope declaration, not a substitute for a per-file provenance manifest.
