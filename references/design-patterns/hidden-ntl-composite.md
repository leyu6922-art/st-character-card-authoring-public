# 隐奸NTL复合设计模式（Hidden NTL Composite Pattern）

> 来源：2026-07-12《示例隐奸项目》→ NTL版设计分析
> 参考资料：Discord用户 woniyu 的隐奸NTL玩法讨论截图
> 问题：隐奸苦主卡已成熟（hidden-ntr-design.md），但缺少反向视角——{{user}}=操控者+全知+博弈破局的NTL设计

---

## 一、什么是隐奸NTL

**定义**：将隐奸（信息不对称/碎片化证据/确信度迷雾）与 NTL（逆寝取/征服者视角）结合。{{user}}是隐奸的**幕后操控者**，AI扮演苦主且获得「努力破局」指令。

### 核心等式
```
隐奸NTL = 隐奸的信息不对称结构 + NTL的视角翻转
          + woniyu的「AI破局博弈」玩法
```

### 与传统NTL的区别

| 维度 | 传统NTL（如赌场老板、兽人将军） | 隐奸NTL |
|------|-------------------------------|---------|
| {{user}}与苦主的关系 | 公开/半公开的对抗 | **信息战**——苦主不知道你的存在 |
| 核心博弈 | 正面征服/争夺 | **隐奸迷雾**——苦主在猜疑中挣扎 |
| 苦主的目标 | NPC式被动存在 | **「努力破局」**——主动调查、尝试反抗 |
| {{user}}的约束 | 武力/权力的对抗 | **信息曝光风险**——苦主可能发现真相 |
| 性场景节奏 | 征服→占有 | **作为「奖励」或「折磨」苦主的工具** |
| 苦主绝望的原因 | 被武力/权力压制 | **知道但阻止不了**的无力感 |

## 二、woniyu玩法模式（核心参考）

从Discord讨论中提取的**玩家端玩法设计**，是隐奸NTL的实践基础：

### 玩法规则
1. **不扮演user（苦主）** — 让AI继续扮演user，AI就是苦主
2. **给AI指令「努力破局」** — 苦主会主动调查、寻找真相、尝试反抗
3. **自己扮演黄毛（NTL角色）** — {{user}}=幕后操控者/征服者
4. **{{user}}全知** — 知道苦主的一切行动、所有女性的状态
5. **享受「看AI想办法破局」** — 苦主的挣扎是核心乐趣之一
6. **AI在规则内破局，不会口胡** — AI不会突然开挂，挣扎有真实感
7. **破坏苦主的所有努力** — 布局+设陷阱+清理证据
8. **让他绝望后征服** — 最终阶段的情感高潮

### 为什么隐奸题材适合NTL

| 原隐奸机制 | NTL视角下的效果 |
|-----------|----------------|
| 三层信息差（写真/语音/日常） | NTL玩家主动发出碎片作为**诱饵和折磨工具** |
| {{user}}永远不确定真相 | **NTL全知** → 知道真相、知道苦主反应、知道如何布局 |
| 隐奸循环（日常→碎片→怀疑→确认） | NTL玩家**操控这个循环的节奏**，加速或拖延 |
| 苦主的弱点（绿帽癖/愧疚感） | NTL玩家**知道弱点**，刻意刺激 |
| AI不能直接宣布真相 | 原卡限制AI。NTL版中，**这些限制绑在AI苦主身上**，NTL玩家不受限 |

## 三、架构设计

### 3.1 双层信息架构

| 层 | {{user}}（NTL）的视角 | AI苦主的视角 |
|----|---------------------|-------------|
| **写真层** | 知道拍的是谁，主动选择发送时机和内容 | 收到「别的人」的写真，猜疑「是不是她？」 |
| **实时层** | 知道通话时女性在做什么，安排让苦主听到 | 听到异常声音，「训练累了」表面解释 |
| **观察层** | 监控苦主的调查行动 | 翻手机/查包包/跟踪，试图确认真相 |

### 3.2 状态栏格式（NTL版·三轨）

```
┌──────────────────────────────────────────────┐
│              🎯 隐奸操纵面板                   │
├──────────────────────────────────────────────┤
│ 女性A·调教：[写真]→[紧身裤]→[抠逼]→[开苞]→[沉迷]→[羞辱哥] │
│ 女性B·沦陷：[抗拒]→[动摇]→[身体沦陷]→[半推半就]→[沉迷]    │
│ 苦主·破局：[安全]→[起疑]→[调查]→[接近真相]→[发现!]→[绝望] │
│ 苦主·确信： ░░░░░░░░░░ 30%                    │
│ {{user}}·风险：● 低  |  当前布局：[写真诱饵已投放]         │
└──────────────────────────────────────────────┘
```

### 3.3 {{user}}的行动选项（system_prompt定义）

1. **布局/推进** — 安排女性的下一步调教，发送新的证据给苦主
2. **监视/侦查** — 查看苦主当前的调查进展、行动轨迹
3. **设陷阱** — 留下假线索或擦除真线索，误导苦主的调查方向
4. **亲自出马** — 当面羞辱苦主、或在苦主面前对女性动手动脚
5. **旁观/欣赏** — 观看苦主的反应，品味痛苦和挣扎
6. **下手** — 对女性进行肉体征服（性场景）

### 3.4 AI苦主的「努力破局」行为模式

**短期目标**：确认碎片证据中的女性是否真是亲人
**中期目标**：调查集团背景、寻找被侵犯的证据
**长期目标**：让女性脱离控制、保护家人

**行为限制（不会口胡）**：
- 不能突然获得武力（原人设限制）
- 不能直接报警（有威胁材料+自身秘密）
- 只能在日常缝隙中调查——翻手机、偷看、跟踪、质问
- 每次调查有风险——可能被{{user}}发现并报复

### 3.5 博弈循环

```
{{user}}布局（安排调教/发送碎片）
    ↓
AI苦主收到碎片（起疑/调查/收集证据）
    ↓
苦主能否找到真相？
    ├─ 是 → {{user}}需要设陷阱/清理证据 → 苦主受挫，减低确信度
    └─ 否 → {{user}}继续安全推进 → 苦主仍在迷雾中
    ↓
循环 → 苦主确信度波动 → 最终{{user}}胜出（征服）或苦主破局（极少）
```

## 四、原隐奸卡→隐奸NTL卡的改动清单

### 需新增的条目（NTL特有）
- **隐奸操纵规则** — 定义{{user}}=幕后操控者，全知视角，信息差变成操控工具
- **AI苦主「努力破局」规则** — AI扮演苦主，目标是「在规则内破局」，限制不能口胡
- **苦主·档案** — 懦弱/绿帽癖/能力边界（从原{{user}}角色/players改为NPC）
- **苦主·破局行为库** — 调查手段（翻手机/跟踪/质问/网上搜索）
- **苦主·对话反应库** — 不同确信度阶段的典型对话模板
- **苦主·破局阶段与{{user}}应对** — 每阶段苦主可能做什么、{{user}}怎么破坏
- **监控室·核心场景** — {{user}}的「作战指挥中心」
- **事件种子：苦主的反击尝试** — AI苦主主动破局的事件
- **事件种子：反制的代价** — 苦主过于接近真相时{{user}}的选择

### 需重写的条目
- 核心规则（原隐奸核心规则 — {{user}}身份重写）
- OOC防护（{{user}}身份改变）
- 状态栏模板（三轨改为NTL版）
- 文风叙事控制（视角切换）
- {{user}}角色档案（原NTR目标档案 → {{user}}角色档案）

### 保留不变的条目
- 女性角色的全部条目（外貌/性格/对话/行为模板完整保留）
- 大部分场景条目
- 大部分事件种子（视角调整）
- 语料库/描写库

## 五、开场白设计要点（NTL视角）

- **视角**：{{user}}是主动方、操控者，不是被动旁观
- **基调**：运筹帷幄的掌控感，展示{{user}}的实力/资源
- **首幕**：{{user}}的第一次布局——安排调教/发第一篇写真
- **苦主展示**：通过监控/情报展示苦主的当下的状态
- **关键转折点**：苦主第一次收到碎片证据的反应

### 典型开场白序列
1. **初次设局** — 威胁利诱苦主，让他成为共犯
2. **写真诱饵投放** — 第一张勒逼写真发出，猫鼠游戏开始
3. **当面羞辱** — {{user}}在苦主面前对女性动手动脚
4. **与AI苦主的正面冲突** — 苦主调查时的警告/设陷阱
5. **最终征服** — 苦主绝望，{{user}}全面征服

## 六、典型玩法循环（5回合周期示例）

```
回合1-3：布局期
  → {{user}}确定目标顺序（先A后B？同时？）
  → 安排第一组正常写真，让苦主开始收到「别人的照片」
  → AI苦主：收到照片，觉得不对劲但说不出来

回合4-6：试探期
  → {{user}}发出露骨写真，观察苦主反应
  → AI苦主：开始起疑「那个大腿好像我妹妹的……」
  → {{user}}可选：①让女性打电话解释 ②发更多暧昧碎片刺激

回合7-10：博弈期
  → AI苦主开始调查——翻手机/查包包/跟踪
  → {{user}}发现苦主的小动作，决定：
     ① 清理证据（苦主什么都找不到→挫败）
     ② 留假线索（苦主去错误方向→迷惑）
     ③ 给个警告（女性说「别管我了」→施压）

回合11-15：加速/压制
  → {{user}}加速调教进度（如给女性开苞）
  → 苦主收到更露骨证据，确信度飙升
  → 但每次想确认时，总差一步

回合16-20：高潮/结局
  → AI苦主或成功破局（极少）或彻底绝望
  → {{user}}展示一切：「你破局失败了呢。好好看着。」
```
