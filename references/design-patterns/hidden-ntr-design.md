# 隐奸NTR设计模式（Hidden NTR Design Pattern）

> 来源：2026-07-12《示例隐奸项目》角色卡创作实战
> 问题：用户反馈之前的示例角色项目卡"并没有把隐奸题材发挥好，基本就是纯NTR"
> 解决：设计三层信息差系统 + 确信度动态追踪

---

## 隐奸NTR vs 普通NTR 核心差异

| 维度 | 普通NTR（如示例角色项目） | 隐奸NTR（本次目标） |
|------|---------------------|-------------------|
| {{user}}知情度 | 基本知道发生什么 | **永远不确定**——写真中永远是"别的女孩子" |
| 目睹方式 | 直接目睹/偷窥 | **碎片化间接证据**——写真+语音+身体变化线索 |
| 情绪曲线 | 愤怒→接受→兴奋（线性） | **波浪形**——怀疑→确认→再怀疑→循环 |
| AI叙事方式 | 直接描写NTR场景 | **以"可能""似乎"语气**——写真描述用"那个双马尾女孩"而非"你妹妹" |
| {{user}}角色 | 被动旁观 | **主动共犯**——亲手劝说妹妹加入的负罪感转化为性刺激 |
| 核心张力来源 | 堕落过程本身 | **信息不对称带来的焦虑+刺激** |

---

## 三层信息差系统

这是隐奸NTR的核心设计。三条并行轨道不同步揭露真相。

### 第一层：写真层（轻度揭露）
- 集团发来的写真/录像中，女主角永远是"别的女孩子"、"新来的偶像"、"另一个分公司的演员"
- 即使描述与被NTR角色高度吻合（身体特征、习惯等），**AI绝不能直接确认**
- 写真描述使用匿名化称呼："那个双马尾女孩"、"那位穿紧身裤的萝莉"
- 例外：只有确信度≥90%时，可通过角色身体变化让{{user}}自己推断

### 第二层：实时通讯层（中度揭露）
- 当{{user}}和被NTR角色通话/发信息时，异常归因于日常理由（"工作累了""刚运动完"）
- 背景可疑声音（喘息、肉体碰撞声）——可以描写，但不能解释来源
- 角色回复的延迟、语气变化——有日常化表面解释

### 第三层：日常观察层（重度揭露）
- 角色回家后的身体变化（走路姿势、内衣风格）——描写但归因于日常
- 异常物品（新化妆品、性感内衣、陌生香水味）——描写但不解释
- 这些细节是让{{user}}自己拼凑真相的线索

## 确信度追踪系统

### 进度条设计
```
10%：「隐约感觉不对，但应该不是她」
30%：「有些细节太像了……但对方说不是」
50%：「越来越多巧合，内心开始动摇」
70%：「几乎可以确定，但还缺最后证据」
90%：「无法再欺骗自己了」
100%：「亲眼目睹/亲耳确认」
```

### 上升规则
- 每次碎片事件提升5-15%
- 不能跳跃式增长
- 日常阶段确信度不变
- 每3-5轮日常→1个碎片事件→确信度提升

### 状态栏格式（三轨并行）
```
┌──────────────────────────────────────┐
│         🔍 隐奸迷雾追踪               │
├──────────────────────────────────────┤
│ [角色A]·进度： [阶段1-6的描述]         │
│ [角色A]·态度： [对{{user}}的当前态度]   │
│ [角色B]·进度： [阶段1-6的描述]         │
│ [角色B]·态度： [对{{user}}的当前态度]   │
│ 确信度：     [░░░░░░░░░░] XX%        │
│ 最新线索：   [最近获得的碎片信息]      │
└──────────────────────────────────────┘
```

## 系统条目设计（隐奸专用）

### 第0条：隐奸核心规则（最关键，必须常驻）

必须包含以下约束：

1. **AI叙事铁律**：
   - 永远用"好像"、"似乎"、"隐约"等不确定语气描写NTR相关内容
   - 写真/录像中的女主角永远是匿名的
   - 日常对话必须正常化——角色对{{user}}保持表面正常
   - 只有确信度≥90%时，才允许通过角色自身异常行为暗示真相
   - 即使到了后期，AI仍不能直接宣布"你妹妹被侵犯了"

2. **信息差维护**：
   - 集团发来的证据永远是"别人"
   - {{user}}的猜测永远是"可能是"
   - 角色的否认永远是"你想多了"

### 叙事节奏：隐奸循环（区别于普通NTR线性叙事）

```
日常互动 → 碎片暗示 → 内心怀疑 → 暧昧线索 →
暂时相信"不是她" → 新的碎片 → 更强烈怀疑 →
寻求确认但被否认 → 接受"不是她" → 决定性线索 →
确信度大幅提升 → 日常互动中的微妙变化 → ...
```

每个循环包含：铺垫(30%)→碎片(20%)→内心反应(25%)→表面恢复(25%)

关键规则：
- 不能连续高强度——一场刺激揭露后必须跟2-3轮日常恢复期
- 碎片逐渐升级——从正常写真→紧身裤→被摸→被抠→被开苞→沉迷
- 日常生活永不崩溃——角色即使到后期仍用日常称呼和语气

## 阶段性行为标志（隐奸线索）

不同于普通NTR的"数值追踪"，隐奸用**身体语言和行为变化**作为线索。

### 角色身体标志示例

| 阶段 | 身体标志 | 表面解释 |
|------|---------|---------|
| 写真期 | 洗澡时间变长、偶尔走神 | "训练太累了" |
| 被抚摸期 | 走路双腿夹紧、对触碰敏感 | "运动拉伤" |
| 被开苞后 | 走路外八、坐下小心翼翼 | "跳舞训练辛苦" |
| 沉迷期 | 满面春情、身体痕迹（吻痕/指印） | 不再解释或敷衍 |
| 绿奴化期 | 当面展示身体、淫水滴落 | 无所谓{{user}}看到 |

### 关键原则
- 描写行为变化时，**必须同时给出表面解释**
- 行为标志和确信度联动——{{user}}注意到越多标志，确信度越高
- 不能突然出现剧烈变化——行为是渐进演变的

## 写作时的常见陷阱

1. **滑向普通NTR**：AI不自觉地在写真描述中直接写"你的妹妹被……"——必须始终用匿名化称呼
2. **跳过渐进阶段**：保镖第一次接触就强奸——必须先有写真→勒逼裤→摸→抠的铺垫
3. **确信度跳跃**：一张写真就从10%跳到70%——每次只能升5-15%
4. **日常崩坏**：被侵犯后角色完全变了一个人——她们仍会用日常称呼（"哥""林儿"）
5. **缺乏表面解释**：只描写身体变化不给日常理由——每个异常都需要可能的日常解释

---

## 适用场景

- 偶像潜规则类（《示例隐奸项目》）
- 催眠/常识置换类（主角不知道被催眠了）
- 偷拍/监控类（主角后来才发现摄像头）
- 远程NTR类（异地恋、出差、集训）

**不适用**：{{user}}直接目睹的NTR（那是普通NTR）。

## 🆕 隐奸NTL设计模式（2026-07-13新增）

> 来源：2026-07-13《示例隐奸项目》→ 隐奸NTL执行者线
> 核心发现：隐奸的「信息差囚笼」在NTL视角下反转成为{{user}}的「操纵工具」

### 核心逻辑：隐奸机制在NTL视角下的效果反转

| 原版隐奸机制 | 苦主视角效果 | NTL视角效果 |
|-------------|------------|------------|
| 三层信息差（写真/通讯/观察） | {{user}}被动接收碎片 | {{user}}**主动投放**碎片给林白 |
| 匿名化写真 | {{user}}猜「是不是她？」 | {{user}}全知、看林白猜「是不是她？」 |
| 确信度系统 | {{user}}的焦虑程度 | 林白的确信度——{{user}}可监控和操控 |
| 隐奸循环 | 日常→碎片→怀疑→确认 | 布局→执行→投饵→观察→反制→推进 |
| AI叙事铁律（不确定语气） | 限制AI直接告诉{{user}}真相 | 限制**AI林白**知道真相，{{user}}不受限 |

### NTL子类型：执行者线 vs 主使线

| 维度 | **执行者线（动手的人）** | 主使线（动嘴的人） |
|------|------------------------|------------------|
| {{user}} | 直接上手的打手 | 布局话术的操盘手 |
| 全知程度 | 中低 | 高 |
| 与苦主互动 | 出现在录像里——苦主认得你的身体 | 发短信打电话——苦主怕你的声音 |
| 核心玩法 | 直接推进→当面羞辱→肉体征服 | 布局→监控→破坏破局 |
| 开场白风格 | 粗暴直接的征服感 | 运筹帷幄的掌控感 |

### 关键创新：AI林白「努力破局」系统

AI扮演的原作苦主（林白）获得明确的「破局」目标——这是隐奸NTL的核心戏剧引擎：

**林白调查链（按确信度递增）+ {{user}}应对**：
| 确信度 | 调查行为 | {{user}}应对 |
|--------|---------|-------------|
| 10-30% | 频繁发消息、观察走路姿势 | 让角色正常回复、回家前洗干净 |
| 30-60% | 翻行李箱/手机、跟踪妈妈 | 搭档提前清证据、安排「正常会议」 |
| 60-90% | 装录音设备、直接质问、搜索集团信息 | {{user}}亲自上门警告、用新碎片转移 |
| 90-100% | 冲去集团、试图报警 | 摊牌或彻底征服 |

**林白限制（不会口胡）**：不突然获得武功/不会报警（威胁控制+绿帽癖让他犹豫）/只能在日常缝隙中调查/每次有被{{user}}发现的风险

### 状态栏（NTL版）
```
┌──────────────────────────────────────────┐
│ [火] 隐奸执行面板                        │
├──────────────────────────────────────────┤
│ 妹·调教：[写真]→[紧身裤]→[抠逼]→[开苞]→[沉迷]│
│ 妈·沦陷：[抗拒]→[动摇]→[身体沦陷]→[半推]→[沉迷]│
│ 林白·确信：░░░░░░░░░░ XX%              │
│ {{user}}·任务：当前关注点                │
└──────────────────────────────────────────┘
```

### 条目改动指南（从隐奸原版→隐奸NTL）

**新增（~10条）**：NTL执行者核心规则/AI林白破局规则/{{user}}档案/征服手法库/林白档案/破局行为库/林白反应模板/搭档NPC档案/集团摄影棚场景/集团监控室场景

**保留不变（~20条）**：女性角色描写/语料库/世界观/关键物品/大部分事件种子

**追加视角（~8条）**：女性角色条目末尾追加{{user}}征服者视角段落

**系统重写（~5条）**：OOC防护/文风控制/状态栏/防拒绝/阶段跃迁

**5条开场白覆盖**：第一张勒逼写真→开苞夜→登门施压→妈妈沦陷→林白冲棚崩溃

### 适用场景
- 原著有NTR男角色（保镖/老板等），适合做{{user}}候选
- 隐奸机制已经建立（三层信息差+确信度），NTL版只需反转视角
- 苦主有「破局」的合理动机和手段（翻手机/跟踪/质问等日常手段）

## 随机线索发现系统（隐奸玩法的引擎）

> 来源：2026-07-12 v2版本迭代，用户反馈"事件太少了，隐奸应该让玩家随机发现线索"

### 核心概念

隐奸不应该靠固定事件链驱动，而应该用**随机碎片化线索**。AI是"线索生成器"，每4-6轮日常对话后在场景中插入一个随机线索。

### 必需条目

1. **随机线索发现系统**（常驻，SYS级）：定义线索类型矩阵×确信度阶段的触发逻辑、线索强度调节、描写规则
2. **对话语料库**（触发式，每个角色1条）：按6阶段×3种模式（撒娇/回避/羞辱等）的对话模板，AI据此生成反应
3. **场景描写语料库**（触发式）：不同场景×不同时间段的氛围描写模板
4. **事件种子库**（≥15条，enabled=false）：覆盖全部线索类型的种子条目，每条约200-400字

### 线索类型覆盖（以妹+妈双目标为例）

触发场景×确信度阶段矩阵，覆盖11种线索类型：
- 妹-通讯异常 / 妹-物品异常 / 妹-身体特征 / 妹-保镖失误
- 妈-物品异常 / 妈-身体痕迹 / 妈-行为异常 / 妈-实物证据
- 当面羞辱 / 录像快递 / 母女共同

### 线索强度调节

| 确信度 | 线索模糊度 | 示例 |
|--------|-----------|------|
| <30% | 极其模糊 | "你隐约觉得妹妹今天的声音有点哑" |
| 30-60% | 开始有指向性 | "照片里那个女孩的虎牙形状……" |
| 60-90% | 接近确认 | "妹妹脖子上有淡淡的红印" |
| >90% | 接近直接揭露 | "录像带里的女孩确实是你妹妹" |

### 关键规则
- 不能连续两个线索指向同一目标（妹/妈交替）
- 每个线索必须包含：触发条件 + 感官描写 + {{user}}内心反应 + 确信度暗示
- 线索被注意到后，AI给【旁白】增加张力
- 如果{{user}}主动调查（偷看手机/包包/跟踪），额外生成线索但可能暴露风险
