# 女主阳具尺寸感知模板

> **来源**：2026-07-18·艳母的荒唐赌约递进式NTR苦主卡构建实证
> **适用卡型**：NTR苦主卡、后宫卡、多男竞争卡、任何涉及多名男性角色且有性描写的卡片

## 1. 为什么需要感知模板

当卡片涉及多名男性角色时，AI默认只会写"他的阳具很大/很粗"这类笼统描述。给女主的Layer 1基础不变量中加入一份**对不同男人的尺寸感知模板**，能让AI：

- 在性爱场景中自动生成差异化描写
- 为苦主感提供具体的对比素材（"儿子不如赵勇大"）
- 为角色关系增加身体记忆维度（"骆鹏那根弧度一进来她就腿软了"）
- 避免重复——每个男人的尺寸特征不同，AI不会写成同一套

## 2. 模板结构

在女主的基础不变量条目（Layer 1，如郎玉诗 id 5）中加入以下内容：

```
【阳具尺寸感知模板】她能准确区分每个男人的阳具差异：
- [男A]：让感到"满了"——[具体描述]
- [男B]：让感到"准了"——[具体描述]
- [男C]：让感到"重了"——[具体描述]
- [{{user}}]：让感到"亲了"——[情感加成描述]
```

### 示例（来自艳母vs赵勇/骆鹏/向晓东/刘宇）

```
【阳具尺寸感知模板】郎玉诗能准确区分每个男人的阳具差异，这是她身体记忆的核心资产：
- 赵勇的尺寸让她感到"满了"——22cm的巨物把阴道壁完全撑开的充实感，这是她最熟悉也最安全的性体验。她常把其他人比作"不如小勇舒服"。
- 骆鹏的形状让她感到"准了"——20cm且带弧度的怪刃专门刮她的G点，让她在最短时间内失控喷水。她害怕这种精准，因为这证明身体可以绕过大脑。
- 向晓东的粗度让她感到"重了"——17cm的粗棍硬塞进来，每次都让她倒吸一口凉气。享受谈不上，但野蛮的冲击有时意外解压。
- {{user}}的尺寸让她有复杂的情感反应——"这是儿子的身体"这个认知本身就有强烈的心理加成。她私下对比过：尺寸确实不如赵勇的22cm，但年轻和亲密感让体验完全不同。她从不主动和{{user}}讨论尺寸比较，但会在被其他人操过后，用更温柔的方式和儿子做爱。
```

## 3. 尺寸梯队设计原则

| 角色定位 | 尺寸范围 | 特色 | 体验关键词 |
|---------|---------|------|-----------|
| 第一征服者（标杆） | 最大（18-22cm） | 粗壮饱满，龟头圆大 | "满了"——阴道壁撑开的充实感 |
| 规则控制者（差异化） | 中长+形状怪（16-20cm） | 上翘/棱状凸起，专门压迫G点 | "准了"——不让大脑反应的精准刺激 |
| 粗变量/蛮力型 | 最粗但偏短（14-18cm） | 蘑菇状龟头，单次冲击力强 | "重了"——纯重量和频率 |
| {{user}}（苦主/操盘者） | 中上（15-19cm） | 匀称，年轻，有情感加成 | "亲了"——禁忌感和情感牵动的复合体验 |

**关键原则**：
- {{user}}的尺寸必须在角色描述中明确标注"不如赵勇"（或其他第一征服者），制造苦主感落地点
- 尺寸梯队可以整体上移（如全部+2-3cm），但**排名不变**——标杆永远最大
- 如果小说原文有尺寸描述（如骆鹏"形状特异的阳具"），必须忠实于原文，不能自创矛盾数据

## 4. 关联情感线铺垫

尺寸感知模板的另一作用是**自然铺垫情感线**：
- {{user}}和别人的区别不只是"大小"，而是"亲密感/情感加成"
- 女主会在被其他人操过后，用**更温柔的方式**和{{user}}做爱——这个细节本身就是情感线的证据
- 写尺寸感知时，给{{user}}独特的情感维度（而非纯粹物理比较），让AI在生成时自动差异化对待

## 5. 放置位置说明

- 尺寸感知模板放在**女主的Layer 1基础不变量**条目中（如郎玉诗 id 5）
- 每个男性的具体尺寸（厘米数+形状描述）放在**各自的Layer 1基础不变量**条目中（如赵勇 id 7、骆鹏 id 8）
- 尺寸感知模板是"她怎么感受他们"，尺寸描述是"他实际有多大"——两者分开写，互相引用
- 不要在事件种子或阶段条目中重复写尺寸——只需要在叙事中自然引用比较
