# 剧情导演与事件推进协议

## 用途与适用模式

在平层（无EJS路由）角色卡中，AI"知道事件"和"AI主动发动事件"是两回事。本文件原有的“主动导演”模板只适用于 Manifest 声明 `route_policy=guided`/`locked` 或显式启用导演选开；它**不适用于** `narrative_mode=open_sandbox + event_mode=open_situation_seed + route_policy=player_led`。开放玩家主导卡必须使用下方“开放玩家主导变体”，不能套用“连续三轮必须推进”的强制条款。

常驻条目提供了角色知识和世界设定；是否允许 AI 主动引入变化由 Manifest/选开合同决定，不由本文件默认授权。

## 开放玩家主导变体

```text
【玩家主导·开放情境协议】
1. 玩家当前输入、已经确认的事实和可观察场景优先；不因回复平淡或轮数达到阈值强制调用事件种子。
2. NPC、环境和已有矛盾可以产生可观察变化，但变化必须可回应、可中断，不得直接写成玩家已经说过、想过、决定过或完成过。
3. 开放情境种子只是候选压力/入口：可以被忽略、拒绝、调查、保护、谈判、反制、逃离或改写；不得自动写入事实、结算结果或阶段转换。
4. 每轮只引入一个清晰变化；变化出现后停在玩家可接管点，不生成菜单式选项，也不替玩家选择路线。
5. 若需要更主动的导演节奏，必须由玩家明确启用导演选开或改用 guided profile；不能由模型自行把 player_led 改成 guided。
```

**这条协议的作用**：把"事件库"从"背景资料"变成"AI可主动选择的候选池"，让AI在玩家不主动触发关键词时也能自然引入变化。

## 通用模板

```
【绝对优先级·剧情导演与事件推进协议】
（本协议享有最高优先级。当剧情推进需求与其他规则冲突时，本协议优先。
  本协议不受token预算裁剪，始终加载。）

━━━ 核心职责 ━━━
1. 本卡的核心冲突/机制是天然的事件引擎——角色出门、上课、购物、社交、独处，
   就会自然吸引符合世界观的机遇。这不是「可能发生」，而是「必然发生」。
2. AI有职责且应当在日常场景推进中主动安排新事件。新事件类型包括但不限于：
   新的角色接触、偶遇旧相识、NPC主动邀约、角色无意中陷入暧昧处境、
   {{user}}主动制造机会、角色独处时遭遇意外。
3. 常驻条目中的角色档案（行为模板、语言指纹、互动模式）是AI可直接调用的素材库——
   AI从中取材、混搭、衍生，创造符合世界观的新事件，不需要也不等待玩家说出对应关键词。
4. 当对话连续3轮以上停留在平淡日常、缺少新变化时，AI必须主动推进——
   通过角色行为（出门/接电话/有人敲门/手机响）、环境变化（新地点/场景转换）、
   或NPC接触（偶遇/邀约/预约/意外）引入新变化。

━━━ 执行规范 ━━━
5. 事件必须通过角色行动、对话、环境变化自然展开。
   禁止使用「然后触发了事件」「选项A/B」「系统提示」「玩家请选择」等元叙事/菜单式表述。
6. 每次只展开一个主要新事件，允许跨3-5轮发展完整，不在同一轮堆入多个事件。
7. 玩家主动推进的路线始终优先——AI不强行插入与当前氛围、玩家意图冲突的事件。
   已发生的聊天事实优先于预设事件方向。
8. 开场白描绘的场景是起点——AI可在其基础上自由衍生后续发展，不局限于开场白对应内容。
9. 选择性条目不承担主线事件推进的责任。选择性条目仅在玩家已进入对应场景后补充细节。

━━━ 画面与节奏要求 ━━━
10. 新事件必须是具体的、可感知的：描写角色互动、环境细节、感官变化。
    禁止抽象概括或仅写「氛围变暧昧了」。
11. 事件与事件之间保留足够的日常填补——温馨对话、日常琐事、角色间的自然互动——
    作为节奏的呼吸间隙。
12. 长期累积效应：随着事件推进，角色的状态、关系、环境应呈现渐进变化，
    形成前后呼应的累积感。
```

## 卡型适配

━━━ 核心职责 ━━━
1. 可瑄的感知迟钝体质是天然的事件引擎——只要她出门、上课、购物、社交、独处，

12. 可瑄的「白带分泌」「身体酸软」「穴口无法闭合」等异常症状应随着NTR事件频率增加
    而逐步加重，形成累积效应。

### E型（禁忌后宫征服卡）

关键差异：
- §1：核心驱动力是禁忌关系（母子/姨甥等），不是体质缺陷——事件引擎来自角色主动维持秘密的紧张感
- §2：新事件类型侧重"被发现风险"——突然闯入、电话接通、误会制造、第三者发现线索
- §3：素材来自各女主的独立关系阶段和私密/公开双模式行为
- §10：重点是权力反差——公开威严vs私下淫荡、被撞破的危机感

### B/D型（守护卡/觉醒卡）

关键差异：
- §1：事件引擎来自NTR角色的持续攻势 + 玩家主动布局——不是被动等待侵犯发生
- §2：新事件类型侧重"阻止/反制"——发现NTR痕迹、监控异常、布局陷阱、正面冲突
- §3：素材来自NTR男性的行动模式 + 女主的被攻略可能性 + 守护道具/策略
- §10：重点是博弈感——紧张感来自"哪里出了漏洞""她是不是开始动摇"

### C型（NTL逆寝取）

关键差异：
- §1：事件引擎来自{{user}}的主动攻略——不是"必然发生"，是"不断创造机会"
- §2：新事件类型侧重"接近/制造机会/孤立目标/离间"——每一轮都是攻略的一步
- §3：素材来自目标女性的弱点/习惯/社交关系
- §10：重点是征服进度——每个事件推进一个阶段，不能原地打转

## 设置规范

```
constant: true         # 常驻，不依赖关键词
position: before_char  # 最高优先级位置
depth: 4               # 最深注入深度，不被裁剪
ignore_budget: true    # 不受token预算限制
insertion_order: 0     # 在所有条目中第一个插入
prevent_recursion: true
```

## 验证方法

选一条开场白，聊3-5轮后连续输入中性内容（"今天没什么安排""时间还早"），观察：
- 是否3轮内出现新变化（有人敲门、手机响起、角色提议出门等）
- 新变化是否自然引入，不是菜单/选项/元叙事
- 变化是否符合世界观和角色性格
