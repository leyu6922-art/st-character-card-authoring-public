# 守护卡原型设计参考

> 来源：校园媚黑女友们的即堕寝取·守护卡项目（2026-07）

## 核心设计理念

"如果什么都不做，原著剧情就会发生" — 这是守护卡的基础假设。原著剧情是"命运线"，玩家的选择可以改变走向。

**关键区别于恶堕卡：**
| 维度 | 恶堕卡 | 守护卡 |
|------|--------|--------|
| 女主起始状态 | 已堕落 | 未堕落（堕落度=0） |
| 玩家身份 | 苦主/旁观者 | 守护者/行动者 |
| NTR内容 | 主体 | 失败惩罚 |
| 结局 | 堕落BAD END为主 | 多结局光谱 |

## 剧情节点系统（LLM即游戏引擎）

SillyTavern没有传统游戏引擎，LLM本身就是引擎。状态追踪通过：
- **状态栏**：每场景开头显示（堕落度/信任度/力量等级/威胁警报）
- **世界书条目**：constant条目=系统规则，keyword条目=剧情节点触发
- **系统提示词**：游戏规则、决策处理逻辑、状态更新指令

### 节点结构

```
Phase 1: 入学篇 (Node 1-3)
Phase 2: 试探篇 (Node 4-7)
Phase 3: 危机篇 (Node 8-10)
Phase 4: 媚体觉醒 (Node 11-13)
Phase 5: 暗流涌动 (Node 14-15)
Phase 6: 终局 (Node 16)
```

每个节点包含9个要素：
1. 触发条件（时间/事件/状态阈值）
2. 场景描述（AI叙述什么）
3. 玩家选择（2-4项，每项有明确后果）
4. 状态变化（具体数值：+15/-20等）
5. **连锁反应**（此选择如何影响未来节点，不只是下一个）
6. 自动推进条件
7. 失败标志
8. **原著对照**（"什么都不做"的默认NTR结果，含场景要点）
9. **最佳策略提示**（完美路线的暗示，不直接给答案）

**高级要素（可选增加）：**
- **隐藏选择**：仅在特定条件满足时出现（如心火诀>30%或已知悉堕落之吻）
- **叙事样本**：2-3句示范文字，告诉AI每个选择后应该写什么风格和语气

### 节点间的关系

```
节点N → 玩家选择 → 后果演绎 → 状态更新 → 自由行动期 → 节点N+1
                                              ↑
                                     可插入支线事件/修炼/约会
```

## 状态系统设计

### 主角状态
- 力量等级：E→D→C→B→A→S
- 心火诀进度：0-100%
- 意志力：影响对NTR诱惑的抵抗力
- 人脉资源：与龙组成员的关系
- 已知情报：解锁的关键信息列表

### 每位女主独立状态
- 堕落度：0-100%（0%=纯洁，100%=完全臣服）
- 信任度：对玩家的信任
- 爱意度：对玩家的爱情
- 当前威胁：哪些NTR角色在瞄准她
- 特殊状态：如"已被堕落之吻影响"、"正在被胁迫"

### 堕落度行为阶梯
| 堕落度 | 行为特征 |
|--------|----------|
| 0-15% | 正常恋爱关系，偶有不安 |
| 15-30% | 开始产生幻想，身体敏感度上升 |
| 30-50% | 身体反应明显，心理开始动摇 |
| 50-70% | 主动寻找刺激，对玩家撒谎 |
| 70-90% | 沉迷快感，公开挑逗NTR角色 |
| 90-100% | 完全臣服，反过来羞辱玩家 |

## NTR角色威胁系统

每个NTR角色有"活跃度"（0-100%），不遏制则自动增长。不同角色有不同的攻击模式：

| NTR角色 | 攻击方式 | 难度 | 反制要点 |
|---------|----------|------|----------|
| 黄浩 | 裸照威胁 | 低 | 取回照片/物理压制 |
| 布鲁德 | 堕落之吻+双修 | 极高 | 避免接触/提升女主意志 |
| 吴林 | 肉棒征服+长期渗透 | 中 | 拆穿/隔离 |
| 刘涛 | 权力胁迫+把柄控制 | 高 | 收集反制证据 |
| 山口武藏 | 身体征服+文化入侵 | 中 | 武力或策略驱逐 |

### 堕落之吻机制
- 效果：与布鲁德法式接吻的女性获得10倍快感，持续72小时
- 叠加：每次接吻加深效果
- 解法：(1) 72小时内不接触；(2) 柳媚仙天生媚体免疫；(3) 心火诀高阶可净化
- 设计目的：让"拯救"不是简单地说服回来

## 决策影响矩阵

| 决策类型 | 早期成功率 | 后期成功率 | 代价 | 适用场景 |
|----------|-----------|-----------|------|----------|
| 暴力对抗 | <10% | 60-80% | 受伤/暴露 | D级以上才有效 |
| 智取/策略 | 40-60% | 70-90% | 时间/情报 | 需要先收集信息 |
| 求助/联盟 | 30-50% | 50-70% | 人情/暴露弱点 | 龙组盟友可用时 |
| 忍耐/潜伏 | 0% | N/A | NTR推进 | 用于积蓄阶段 |
| 修炼/成长 | N/A | N/A | 短期无保护 | 长期投资 |

## 结局系统

至少6种结局，按状态变量阈值判定：

1. **完美守护**：所有堕落度<20%，所有信任>80%，力量A+
2. **苦涩胜利**：4+女主堕落度<50%，但有永久伤痕
3. **部分夺回**：2-3女主恢复，其余堕落
4. **孤独英雄**：力量A+但多数女主堕落度>60%
5. **苦主BAD END**：多数堕落度>80%，力量<C
6. **堕落BAD END**：玩家意志力降至0，主动鼓励NTR

## 自由行动期设计

节点间有"自由行动期"，玩家可以：
- **修炼**：提升力量等级（消耗时间）
- **约会**：提升女主信任/爱意（消耗时间）
- **侦查**：收集NTR角色情报（有风险）
- **社交**：与龙组成员建立关系（解锁盟友）
- **策略**：主动干扰NTR角色的计划

资源有限，不可能同时做所有事 → 优先级判断是核心玩法

## 开场白连续链设计（v3验证，2026-07）

守护卡的开场白不同于恶堕卡——需要按原著时间线排列并有衔接引导。

### 设计原则
1. **纯叙事，不含状态栏/选项** — 状态栏和选项由system_prompt控制AI自动生成，不要嵌入greeting
2. **按时间线排列** — 8/31→9/1→9/2→第一周→第二周→...，避免v2的时间线倒序问题
3. **每个greeting结尾引导下一个** — 自然过渡，不突兀
4. **数量≥10个** — 覆盖原著全时间线的关键转折点

### 开场白时间线模板
```
alt[0]: 序章（父亲遗信/母亲送别/前情）
first_mes: 第1章核心场景（报到日/初次冲突）
alt[1]: 第1-2章衔接（未婚妻登场/初遇新角色）
alt[2-3]: 第一周事件（图书馆初遇/深夜危机）
alt[4-5]: 第二周事件（初吻危机/宿管威胁）
alt[6-7]: 第三周事件（电影院带走/摊牌威胁）
alt[8-9]: 第四周+事件（心火诀觉醒/高潮场景）
```

### 衔接示例
- alt[0]结尾："明天就是9月1日。华美大学报到日。你的命运，在那里等着你。"
- first_mes结尾："叶云的手还在发抖。但他的眼睛里，有什么东西正在改变。"
- alt[1]结尾："远处篮球场，布鲁德收回了目光。叶长风的儿子……有意思。"

### 常驻条目token优化
v2用15个const条目（~6600 tokens），v3精简到8个（~4640 tokens，-30%）：
- 合并相关条目（世界观华美大学+龙组→一个800字段落）
- 将低频触发的系统条目（如堕落之吻机制）改为keyword触发
- 消除system_prompt与const条目内容重复
- 关键系统规则放system_prompt，详细机制放keyword条目

## 设计注意事项

1. **堕落度初始值**：除有特殊过去的角色外，全部=0
2. **难度不能太低**：玩家一句话不能阻止堕落，需要过程和代价
3. **NTR场景要有冲击力**：作为失败惩罚，要让玩家感到"下次一定要做得更好"
4. **多条路线并行**：修炼/权力/情感可以同时推进但资源有限
5. **自由行动期很重要**：这是玩家主动性的主要出口
6. **状态栏必须常驻**：每次场景切换都要更新，否则玩家失去方向感
