# 多NPC信息边界设计

## 问题

AI同时扮演多个NPC时，默认所有NPC全知——A角色知道B角色不知道的事、C角色能看到{{user}}在偷看、D角色能说出本不该知道的信息。后果：

- 隐奸/偷窥题材：NTR施害方自动知道{{user}}在窗外看 → 偷窥体验失效
- 多NPC对峙场景：各角色对{{user}}的信息量相同 → 信息差博弈消失
- 秘密/潜伏玩法：{{user}}以为自己是暗处的 → AI默认所有NPC都知道你在那

## 适用于

**所有多NPC角色卡**（NTR苦主/NTL征服者/守护/后宫/叙事观察卡），不限题材。

## 设计结构

两条线并行：一条**全局规则**定义各角色间的信息关系，一条**按角色分段**嵌入具体条目。

### 全局信息边界条目（常驻，keys=[]）

```markdown
【信息边界·全局规则】（常驻·系统）

┌─ 一、初始信息状态 ─────────────────────────┐
│                                            │
│ A角色（{{user}}）                           │
│   ├─ 对NPC甲：知道身份·不知道正在偷看        │
│   ├─ 对NPC乙：完全不知道存在                  │
│   └─ 空间感知：能看到房间·听不到隔壁对话      │
│                                            │
│ NPC甲                                       │
│   ├─ 对{{user}}：以为只是路人·不知道在监视   │
│   ├─ 对NPC乙：共享信息·认为对方是同伙        │
│   └─ 行为范围：只在自己房间·不去楼下          │
│                                            │
│ NPC乙                                       │
│   ├─ 对{{user}}：完全不知道存在              │
│   ├─ 对NPC甲：不完全信任·隐瞒部分事          │
│   └─ 行为范围：全区域活动                     │
│                                            │
│ 空间默认规则：                               │
│ ├─ 不在同一房间 = 不感知对方行动             │
│ ├─ 隔壁房间 = 能听到模糊声音·听不清内容      │
│ └─ 短距离内（同一条街）= 有可能偶遇          │
│                                            │
├─ 二、信息变化阶段（可选）──────────────────── │
│                                            │
│ 阶段1（初始）：NPC甲不知道{{user}}的真实身份  │
│ 阶段2（冲突）：NPC甲发现真相但NPC乙仍然不知   │
│ 阶段3（后期）：所有NPC信息逐步打通           │
│                                            │
├─ 三、冲突优先级 ──────────────────────────── │
│                                            │
│ 具体场景描写 > 本规则                       │
│ 如果某个场景写明了"他看向了你"，              │
│ 即使规则说"不知道你的存在"也该场景优先        │
│                                            │
└────────────────────────────────────────────┘
```

### 空间感知粒度

信息边界不只是"知道/不知道"，还有空间感知。对隐奸/偷窥/潜伏题材**尤其重要**：

| 空间关系 | 默认感知级别 | 能做什么 |
|---------|------------|---------|
| 同一房间·视线内 | 全感知 | 看到动作、听到对话、感知情绪 |
| 同一房间·背对 | 听觉+嗅觉 | 能听到说话但看不到表情 |
| 隔墙/隔壁 | 模糊听觉 | 能听到有人在说话但听不清内容 |
| 隔一层楼 | 震动感知 | 能感觉到动静但无法分辨 |
| 不同房间·视线盲区 | 无感知 | 完全不知道对方在做什么 |
| 不同建筑 | 零 | 零 |

**空间感知的默认规则**：所有不明确的情况，默认NPC之间没有感知。如果需要某个NPC在特定场景中感知到其他人，**必须在场景条目中显式描写**，不能依赖AI自动补全。

### 角色条目中嵌入信息边界

全局规则之外，每个角色条目的末尾嵌入该角色的**信息状态子段**：

```markdown
## 赵高·角色设定

（角色外貌、性格、行为模板等常规内容……）

【信息边界】
├─ 对{{user}}（白齐）：知道他是白若雯的儿子，知道他在门外偷看，但假装不知道。
│  每次侵犯时故意说"你儿子在外面听着呢"来刺激白齐。
├─ 对李明：全面合作，共享白若雯的侵犯权和信息。
├─ 对流浪汉：只给钱和钥匙，不透露白若雯的真实身份。
└─ 空间感知：主要活动在白若雯病房和赵高办公室。出现在医院走廊时会注意周围有没有白齐。
```

这样做的原因：单条独立的"信息边界规则"条目过长时AI容易忽略末尾的部分，而角色条目AI每次触发都会读，信息边界嵌入角色条目中更容易被实际采用。

## 各卡型的配置差异

### NTR恶堕卡（A型）

核心需求：{{user}}作为偷窥者/观察者，NTR施害方**不能**知道{{user}}的存在。

```markdown
关键设定：
- 所有NTR施害方对{{user}}：不知道存在 / 不知道在偷看
- {{user}}对NTR施害方：知道是谁但对方不知道你在哪
- NTR施害方之间：共享信息（同伙）或互不知情（竞争关系）
- 空间感知：{{user}}的观察位置必须安全（阴影/窗外/手机屏幕）
```

### NTL征服者卡（C型）

核心需求：{{user}}作为征服者，AI苦主**知道但无法阻止**，信息差是征服者的工具。

```markdown
关键设定：
- {{user}}对AI苦主：全知（知道你在调查、知道你在哪）
- AI苦主对{{user}}：知道身份/知道部分行动但不知全貌
- 其他NPC对AI苦主：选择性共享信息（取决于帮哪边）
- 空间感知：{{user}}可以监控苦主，但苦主不能看到{{user}}的行动
```

### 守护/觉醒卡（B/D型）

核心需求：{{user}}觉醒后逐步获取信息，NTR施害方**发现**{{user}}在反抗。

```markdown
关键设定：
- 初始：{{user}}信息最少，NTR方信息最多
- 进展：{{user}}逐步发现真相，NTR方逐步发现{{user}}在反抗
- 阶段跃迁：双方信息的此消彼长，触发新的场景
- 空间感知：{{user}}需要寻找证据（翻手机/跟踪/监视）
```

### 叙事观察卡（F型）

核心需求：{{user}}作为无形观察者，NPC**完全不知道**{{user}}的存在。

```markdown
关键设定：
- 所有NPC对{{user}}：零感知（无法看到/听到/感觉到）
- {{user}}对所有NPC：全知（能看到一切）
- 介入风险：一旦{{user}}介入，NPC会察觉到异常
- 空间感知：{{user}}可自由切换视角，但介入会打破信息边界
```

### 禁忌后宫征服卡（E型）

核心需求：后宫成员知道彼此关系，但对外界**严格保密**。

```markdown
关键设定：
- 后宫成员之间：知情（知道彼此是{{user}}的女人）
- 对特定高风险NPC（父亲/丈夫）：零信息（必须不知道）
- 公开模式：所有后宫成员与{{user}}维持正常关系
- 空间感知：在不同场景切换公开/私下模式时必须重置信息状态
  - 锁门=确认安全→可以切换到私下模式
  - 有人敲门=紧急切换回公开模式
```

## 信息边界的动态变化（长线卡）

信息边界不是静态的。剧情推进后角色会获得新信息。对于长篇/多阶段卡，需要定义**阶段变化规则**：

```markdown
【信息变化规则】

阶段1（开端，第1-10轮交互）：
NPC甲对{{user}}：完全不知道存在
NPC乙对{{user}}：知道身份但不怀疑

阶段2（发展，第11-20轮）：
NPC甲开始察觉异样（概率触发：当{{user}}进入禁区3次后）
NPC乙通过某事件发现真相对{{user}}态度转变（由AI根据场景自动触发）

阶段3（高潮，第20轮以后）：
所有NPC信息逐步打通—矛盾爆发—结局分支
```

**阶段变化不要用数值追踪**（"疑惑值≥50→阶段2"），而用**具体行为标志**（"当NPC甲目击{{user}}进入禁区3次后"或"当NPC乙收到匿名信后"）。

## 与现有技能的关系

- 本模式在 **§3.5 加料自检** 中新增：检查是否有3+角色条目 + 无信息边界规则 → 输出warning
- 本模式与 **NPC行为独立性** 同时使用——信息边界管"知道什么"，独立性管"做什么"
- 本模式不依赖任何具体角色名、世界观、题材——纯结构设计

## 踩坑记录

1. **2026-07-13 天仙配**：AI默认所有NPC全知→黑人角色无意识说出"他儿子在窗边看呢"→白齐（{{user}}）偷窥体验失效。修复：增加信息边界常驻规则+每个角色条目末尾嵌入信息状态。
2. **2026-07-13 冷艳教师妈妈**：赵高知道白齐在门外→白齐的"蹲点偷拍"型开场白变得滑稽（赵高会主动摆姿势）。修复：信息边界规则定义赵高"假装不知道白齐在偷看"。
3. **动态变化被忽略**：初次构建时只设了初始信息状态，没设阶段变化规则→后期剧情推进时AI对信息边界的处理开始混乱。修复：长线卡必须包含阶段变化子段。
