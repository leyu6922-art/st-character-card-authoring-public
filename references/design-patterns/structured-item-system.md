# 道具/机制的结构化描述模板

> 源自：大型结构化卡 v4.2「品质效果限定规则」+「技能装备道具生成规则」
> 兼容性：P0 纯文本通用
> 相关模板：模板八「道具/能力进化系统」

---

## 一、核心概念

将道具描述从叙事性的"恶魔相机，可以拍照控制人，有副作用"升级为**结构化字段**：品质等级/类型/使用条件/效果/副作用/进化路线/反噬条件。

AI 不再猜测"这个道具能干嘛"——每个维度都有精确描述。

---

## 二、字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 品质 | ✅ | 普通/稀有/史诗/传说/神话 |
| 类型 | ✅ | 主动/被动/消耗品 |
| 使用条件·消耗 | ✅ | 每次使用消耗什么（资源/道具/代价） |
| 使用条件·冷却 | 推荐 | N轮后可用，防止无限使用 |
| 使用条件·限制 | 推荐 | 什么情况下不可使用 |
| 效果（主动） | ✅ | 主动使用时的精确效果 |
| 效果（被动） | 推荐 | 常驻效果 |
| 副作用 | ✅ | 使用后的负面效果+触发概率 |
| 进化路线 | 推荐 | 初期/中期/后期的效果和副作用变化 |
| 反噬条件 | ✅ | 什么情况下道具会反噬主人 |

---

## 三、条目模板

```
条目名：道具·{道具名}
keys: [{道具名}]
position: before_char

【{道具名}】
品质：普通/稀有/史诗/传说/神话
类型：主动/被动/消耗品
使用条件：
  消耗：每次使用消耗{资源}点
  冷却：{N}轮后可用
  限制：{条件}下不可使用
效果（主动）：
  - 效果1：{精确描述，含数值}
  - 效果2：{精确描述，含数值}
  - 效果3：{精确描述，含数值}
效果（被动/常驻）：
  - {效果描述}
副作用：
  - 副作用1：{描述}（触发概率{X}%）
  - 副作用2：{描述}（触发概率{Y}%）
进化路线：
  初期（使用0-5次）：{基础效果+轻微副作用}
  中期（使用6-15次）：{强化效果+中等副作用+新增能力}
  后期（使用16+次）：{终极效果+严重副作用}
反噬条件：{什么情况下道具会反噬主人}
```

## 四、完整示例

### 例一：NSFW卡·恶魔相机

```
【恶魔相机】
品质：传说
类型：主动
使用条件：
  消耗：每次使用消耗1点灵魂（灵魂上限10点）
  冷却：3轮
  限制：龙傲天在50米内时不可使用（会被感知）
效果（主动）：
  - 拍照：摄取目标的灵魂碎片，获取1段"灵魂记忆"
  - 血祭仪式：消耗灵魂记忆+1点灵魂，下达1条指令（50字内）
  - 指令效力：目标越强效果越弱（对龙傲天无效，对角色D75%生效）
效果（被动）：
  - 灵魂感知：感知50米内有强烈情感波动的目标
副作用：
  - 噩梦：每次使用后当晚必做噩梦（触发概率100%，内容与摄取对象相关）
  - 暴虐冲动：灵魂<5点时，50%概率产生暴力倾向
  - 冤魂反噬：灵魂=0时，相机内冤魂反噬主人（致命）
进化路线：
  初期（0-5次）：单目标单指令，效力弱
  中期（6-15次）：多目标追踪，指令可嵌套2层
  后期（16+次）：可同时对多人下达指令，但每次消耗3点灵魂
反噬条件：灵魂=0 或 试图对第六层级以上目标使用
```

### 例二：冒险卡·星陨之剑

```
【星陨之剑】
品质：史诗
类型：主动
使用条件：
  消耗：每次挥动消耗15点MP
  冷却：无（可连续使用直到MP耗尽）
  限制：夜间使用效果翻倍；白天使用效果减半
效果（主动）：
  - 基础斩击：造成武器攻击力×1.5的伤害
  - 星辰坠落（MP≥50时可用）：对3×3范围造成武器攻击力×3的AOE伤害
效果（被动）：
  - 星光：在黑暗中提供5米范围照明
  - 星辰共鸣：持有者MP恢复速度+20%
副作用：
  - 星蚀：连续使用5次后，MP消耗翻倍（触发概率100%）
进化路线：
  初期：基础斩击
  中期（击杀50个敌人后）：解锁星辰坠落
  后期（击杀200个敌人后）：星辰坠落范围扩至5×5，MP消耗减半
反噬条件：在日光下连续使用10次 → 剑身碎裂，需要修复
```

## 五、品质等级对AI输出的影响

不同品质等级决定了AI描述道具时的"分量感"：

| 品质 | AI应该怎么描述 | 使用时的叙事 |
|------|-------------|------------|
| 普通 | 平凡物品 | "他从口袋里掏出一把钥匙" |
| 稀有 | 有点特别 | "这把钥匙泛着淡淡的蓝光" |
| 史诗 | 引人注目 | "蓝色的光芒照亮了整个房间，所有人转头看来" |
| 传说 | 改变规则 | "空间在钥匙插入的瞬间扭曲了——这不是开门，这是在撕裂现实" |
| 神话 | 改变世界 | "没有人见过这把钥匙——因为见过的人都成了锁的一部分" |

## 六、Pitfalls

> ❌ 道具写成"有副作用"三个字 → AI 自己编副作用，可能编得离谱
> ❌ 进化路线只写"初期更强" → AI 不知道具体什么时候进阶
> ✅ 每个效果和副作用都有精确数值或百分比
> ✅ 进化路线用使用次数/击杀数/天数等可追踪的指标
> ✅ 反噬条件是"安全阀"——防止玩家无限使用
