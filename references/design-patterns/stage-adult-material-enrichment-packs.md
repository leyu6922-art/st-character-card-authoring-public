# 阶段成人素材包加厚模式

适用场景：递进式/阶段路由 ST 角色卡已经能稳定触发世界书，但实机回复仍偏“关系逻辑/心理分析/行为边界”，缺少可直接生成成人向内容的调情语料、淫语句库、身体反应链和性事件示例。

## 核心判断

触发成功不等于可跑。阶段条目如果只写：

- 人物关系判断
- 行为逻辑
- 心理边界
- 阶段禁令
- 事件目录

模型会稳定但“没肉”。这类卡需要补的是**可直接调用的成人素材**，不是继续改路由。

## 单轴伪丰富判据（2026-07-26 新增，加厚前必读）

厚度必须是**信息量的厚度**，不是措辞的厚度。最常见的失败模式：写了大几百 token 的“衍生/分支”，把每条压缩成一句话后发现全部落在同一条轴上（例如“对外伪装清纯、对 user 无底线痴堕”换 N 种措辞重复），这跟直接贴一个“反差母狗”标签没有区别，还会让人格坍缩成谁来都一样的机器人。

自检方法：把每个素材单元的信息量各压成一句话，若两个单元的压缩句可以互换而不损失信息，就是单轴重复——砍掉一个，把篇幅换成**不同轴**的画面感信息量：具体体位/play 差异、身体部位的独立反应链、不同场景下的姿态与声音、被特定动作触发的独特行为（这些才是色情画面感层面的有效信息）。人设层的反刻板方法论见 `persona-contradiction-modeling.md`。

## 推荐结构：每阶段新增一个素材包

不要把旧阶段条目/关系条目全部塞胖。推荐新增独立世界书条目：

```text
成人素材·阶段P0·火玫瑰基准线
成人素材·阶段P1·赵勇初次征服
成人素材·阶段P2·新赌约与多人试探
成人素材·阶段P3·游戏化调教与温泉
成人素材·阶段P4·九局五胜与浪奴命名
成人素材·阶段P5·违约链与多方失控
成人素材·阶段P6·192小时与公开风险
```

字段规则保持当前路由，不回潮复杂过滤：

```json
{
  "keys": ["阶段P1"],
  "secondary_keys": [],
  "selective": false,
  "enabled": true,
  "position": 4,
  "extensions": {
    "position": 4,
    "scan_depth": 2,
    "match_whole_words": false,
    "selective": false,
    "sticky": 0,
    "probability": 100
  }
}
```

## 每个素材包必备章节

每条素材包建议 1500-2600 中文字。不是为了堆字，而是给模型可直接展开的素材。

```text
【本阶段成人向核心味道】
一句话说明这个阶段的“肉味”。

【妈妈对不同人的性反应差异】
按对象拆：{{user}}/赵勇/骆鹏/向晓东/外部人物。每个对象必须有身体反应、心理防御、事后态度差异。

【调情语料】
6-12 句，可直接调用。不同角色语气要不同。

【淫语/羞辱/挑逗句库】
4-12 句，区分妈妈说、对方说、{{user}}听到后的苦主感。

【身体反应链】
3-5 条。每条包含：触发动作 → 第一反应 → 嘴上防御 → 身体背叛 → 对方推进 → 事后残留。

【性事件示例】
2-4 个短事件，每个 250-450 字。必须含地点、人物、动作推进、对话、{{user}}视角、事件后关系变化。

【禁止提前出现】
列出后期称呼、后期协议、后期人物、后期场景边界。
```

## 原文抽取要求

优先从原文抽取，不要凭空写通用黄话。每个素材包最低采集：

- 原文/近原文对白 ≥ 8 句
- 原文场景细节 ≥ 3 处
- 原文行为链 ≥ 3 条
- 阶段专属称呼/关键词 ≥ 5 个

采集表建议：

```json
{
  "阶段P1": {
    "source_chapters": [],
    "dialogue_quotes": [],
    "scene_details": [],
    "action_chains": [],
    "post_event_changes": [],
    "character_differences": {}
  }
}
```

## 旧条目同步小修

新增素材包是主线；旧条目只做小修，不大重写：

- 女主基础档案：追加“成人向反应矩阵·总索引”
- 关键关系条目：每条追加 300-500 字调情/身体反应/事后状态
- P5/P6 风险条目：补“风险如何转化为成人事件”，别只写风险说明

## 验证门控

除标准 `validate_card.py` / `audit_worldbook_triggers.py` / `enrichment_self_check.py --r18` 外，新增检查：

| 检查 | 门槛 |
|---|---:|
| 每个素材包有必备章节 | 必须 |
| 每个素材包对白数量 | ≥6，最好≥8 |
| 每个素材包身体反应链 | ≥3 |
| 每个素材包性事件示例 | ≥2 |
| 路由残留 | 无 `ROUTE_STAGE`、无裸 `P#` key、无 secondary 回潮 |
| enrichment | 0🔴；≤2🟡可人工放行 |

## 收口 pitfall

- `enrichment` 出现 `🟡≥3` 时，不能说“都是软项”直接交付；必须查是否有新增条目导致的新黄项。若是新增素材包缺“行为触发条件”，补 150-300 字即可。
- 检查 mojibake：搜索 `â`。常见为中文引号被写成 `â\x80\x9c/â\x80\x9d`，必须替换为 `“/”`。
- 卡名/报告版本要同步，避免 `v1.17.3` 文件里显示 `v1.17.2`。
- `display_index` warning 可顺手修为与 id 一致，或删除该字段；不是触发阻断，但发布前建议清掉。

## 取舍

素材包会提高每阶段触发负载。这是可接受取舍：发布友好卡优先“触发后有可生成内容”。如果负载过高，先压缩 P5/P6，再考虑拆包；不要牺牲 P1/P3/P4 的核心成人素材。
