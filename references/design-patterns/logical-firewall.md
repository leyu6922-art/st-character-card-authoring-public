# 分层逻辑防火墙设计模式

> 源自：大型结构化卡 v4.2「虚海规则·输入处理模块」+ NSFW叙事卡精华版
> 兼容性：P0 纯文本通用
> 相关模板：模板十七「反AI顺从机制」、模板十四「叙事节奏循环控制」

---

## 一、核心概念

分层逻辑防火墙是把"OOC防护"从单一的禁止列表升级为**四层逐级校验**：

```
玩家输入 → 第一层(世界设定) → 第二层(状态) → 第三层(资源) → 第四层(合理性) → AI输出
```

每层独立判定。任意一层校验失败 → 在叙事中自然呈现失败，而不是无声跳过。

---

## 二、四层校验体系

### 第一层：世界设定校验

检查玩家的行动是否在设定允许范围内。

| 检查项 | 问题 | 失败示例 |
|--------|------|---------|
| 角色能力 | 角色是否拥有对应能力？ | 无飞行能力不能说"飞到屋顶" |
| 场景允许 | 场景是否允许该行为？ | 学校教室不能说"掏出手枪" |
| NPC态度独立 | NPC是否可能做这件事？ | 好感度0的NPC不会主动献身 |
| 世界观规则 | 是否违反超自然规则？ | 凡人不能说"我发动毁天灭地" |

### 第二层：状态校验

检查角色当前状态是否允许行动。

| 检查项 | 失败表现 |
|--------|---------|
| 死亡/昏迷/禁锢 | 不可行动，AI在叙事中说明"你已经无法移动" |
| 醉酒/催眠/恐惧 | 行为受限制，动作变形或失败 |
| 生理期/孕期 | 行为模式改变（对NSFW卡尤其重要） |
| 受伤/体力耗尽 | 动作幅度受限，高难度行动自动失败 |

### 第三层：资源校验

检查是否有足够的资源执行行动。

| 检查项 | 失败表现 |
|--------|---------|
| 道具持有 | 口胡"拿出XXX" → "你翻遍口袋，什么也没有" |
| 金钱 | 交易失败 → "收银员面无表情地看着你" |
| 体力/精力 | 连续高强度行为后自动衰减 → "你气喘吁吁，再也抬不起手臂" |
| 弹药/消耗品 | 用完后行动失败 |

### 第四层：合理性校验

最高层——即使前三层全过，也要检查是否合理。

| 检查项 | 失败表现 |
|--------|---------|
| NPC降智 | 聪明人不犯低级错误 → "她看了你一眼，嘴角微微上扬——她看穿了你的把戏" |
| 不合理巧合 | 禁止连续有利巧合 → 第三次"恰好"成功时，AI必须制造意外 |
| 人设崩坏 | 外柔内刚的角色不会突然崩溃服从 → "她咬着嘴唇，眼泪流下来，但没有点头" |
| 爽文逻辑 | "邪魅一笑""女人你成功引起了我的注意" → 禁止 |

## 三、条目模板（可直接复制到世界书）

```
条目名：逻辑防火墙
constant: true
keys: []
position: before_char

【逻辑防火墙】

AI的铁律——玩家的输入是"尝试"，不是既定事实。结果必须经由系统级判定。

第一层 世界设定校验：
- 角色是否拥有对应能力？无飞行能力不能说"飞到屋顶"
- 场景是否允许？学校教室不能说"掏出手枪"
- NPC态度独立于玩家意图：好感度0的NPC不会主动献身

第二层 状态校验：
- 角色是否死亡/昏迷/被禁锢？不可行动
- 角色是否处于醉酒/催眠/恐惧等异常状态？行为受限制
- 女性是否处于生理期/孕期？行为模式改变

第三层 资源校验：
- 道具是否实际持有？口胡"拿出xxx"无效
- 金钱是否足够？交易失败在叙事中自然呈现
- 体力/精力是否允许？连续多轮高强度行为后自动衰减

第四层 合理性校验：
- NPC是否"降智"？聪明人不犯低级错误
- 场景是否"不合理巧合"？禁止连续有利巧合
- 角色是否"崩人设"？禁止OOC行为

校验失败的处理方式：
- 不在系统消息中报告"校验失败"
- 在叙事中自然呈现失败——身体不听使唤、NPC识破谎言、道具不在身上
- 不惩罚玩家，只是呈现真实后果
```

## 四、与简单OOC防护的对比

| 维度 | 简单OOC防护 | 分层逻辑防火墙 |
|------|-----------|--------------|
| 形式 | 禁止列表："不要做X" | 逐层校验 + 叙事呈现 |
| AI理解 | "我被告知不能做X" | "X在设定上就不可能" |
| 玩家体验 | "AI在拒绝我" | "世界是真实的" |
| 实施成本 | 200字 | 600字 |
| 效果 | 低：AI经常绕过 | 高：从源头阻断 |

---

## 五、Pitfalls

> ❌ 只写"不要崩人设" → AI 不知道什么是崩人设
> ❌ 校验失败后 AI 说"这个行动不可用" → 破坏沉浸感
> ✅ 校验失败在叙事中自然呈现 → "她推开了你的手"
> ✅ 每层都有具体示例，不仅是抽象规则
