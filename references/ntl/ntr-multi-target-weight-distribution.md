# NTR多目标权重分配指南

## 问题背景

在NTR题材的角色卡中，常见的错误是只有一个NTR目标（通常是{{user}}）独占所有戏份，其他NTR目标只是"对照组"。这导致：
1. 玩法单一，缺乏新鲜感
2. 其他NTR目标形同虚设
3. 角色卡的可玩性大幅降低

## 核心原则

**每个NTR目标都是独立的主角，不是配角。**

每个NTR目标必须有：
1. 独立的世界书条目（1000+字，含完整性格、语言风格、行为模板）
2. 至少1-2条独立开场白（500+字/条）
3. 独立的剧情线（征服哪些舰娘、用什么方式、有什么特色）
4. 与其他NTR目标的差异化（身份、体型、性器、征服方式）

## NTR目标类型设计

### 按身份类型
| 类型 | 示例 | 特色 |
|------|------|------|
| 佣兵/军人 | 黑人佣兵马库斯 | 粗暴征服、药物催眠 |
| 指挥官/领导 | 白人指挥官约翰 | 权力胁迫、身份便利 |
| 商人/富豪 | 日本商人山田太郎 | 金钱交易、利诱 |
| 贵族/皇室 | 欧洲贵族亚历山大 | 优雅追求、文化入侵 |
| 海盗/罪犯 | 黑人海盗杰克船长 | 暴力胁迫、囚禁 |
| 运动员/拳击手 | 黑人拳击手泰森 | 体能征服、训练名义 |

### 按征服方式
| 方式 | 特色 | 示例 |
|------|------|------|
| 催眠+药物 | 渐进式控制 | 马库斯用催眠术和药物 |
| 权力胁迫 | 利用身份优势 | 约翰以指挥官身份命令 |
| 金钱诱惑 | 用财富吸引 | 山田太郎用金钱买春 |
| 文化入侵 | 用异域魅力 | 亚历山大用贵族气质 |
| 暴力胁迫 | 直接武力 | 杰克船长用暴力威胁 |
| 体能征服 | 用身体优势 | 泰森用训练名义 |

## 开场白标题格式

每条开场白必须标注当前NTR目标：
```
【章节·场景 | 角色名堕落度X%→Y% | NTR目标：XXX | 特殊状态】
```

示例：
```
【第2章·浴室 | 光辉堕落度50% | NTR目标：马库斯 | 已征服光辉】
【第3章·指挥官办公室 | 光辉堕落度75% | NTR目标：约翰 | 指挥官身份胁迫】
【第4章·高雄宿舍 | 高雄堕落度50% | NTR目标：山田太郎 | 金钱诱惑】
【第5章·女仆休息室 | 贝尔法斯特堕落度75% | NTR目标：亚历山大 | 贵族气质】
【第5章·海域 | 企业堕落度50% | NTR目标：杰克船长 | 暴力胁迫】
【第5章·训练场 | 圣路易斯堕落度50% | NTR目标：泰森 | 体能征服】
```

## 共享舰娘模式（主/副分配）

当NTR角色数量超过舰娘数量时，可以让多个NTR角色共享同一舰娘，形成"主/副"关系：

### 分配原则
- 每个舰娘有一个"主"NTR角色（主要征服者，负责初始征服和主要剧情线）
- 可以有1-2个"副"NTR角色（在主征服者完成后接手，或从不同角度征服）
- 共享关系产生新的玩法：竞争、合作、轮换、比较

### 共享类型
| 类型 | 说明 | 示例 |
|------|------|------|
| 接手型 | 主征服者完成后，副征服者接手日常调教 | 杰克征服圣路易斯 → 布莱克接手调教 |
| 竞争型 | 两个NTR角色同时追求同一舰娘，形成竞争 | 马库斯和亚历山大同时征服可畏 |
| 互补型 | 用不同方式征服同一舰娘的不同方面 | 泰森用力量+约翰用温柔征服企业 |
| 协作型 | 两个NTR角色合作同时征服同一舰娘 | 马库斯+泰森双飞光辉+企业 |

### 共享舰娘的世界书条目设计
当一个舰娘被多个NTR角色共享时，条目中需要标注：
```
NTR归属：马库斯（主）/ 亚历山大（副）
```
并分别描述与不同NTR角色的互动差异：
- 对主征服者：完全臣服，称呼"主人"
- 对副征服者：半臣服状态，称呼"先生"或名字
- 在两个征服者面前：展示不同面向（对A温柔，对B狂野）

### 示例游戏项目案例：6舰娘共享（2026-07-04）
- 可畏：马库斯(主,泳池催眠) + 亚历山大(副,浪漫追求)
- 不挠：马库斯(主,cosparty药物) + 亚历山大(副,花园钢琴)
- 企业：泰森(主,拳击馆力量) + 约翰(副,温柔理解)
- 高雄：约翰(主,训练场温柔) + 泰森(副,道场格斗)
- 圣路易斯：杰克(主,牢房暴力) + 布莱克(接手) + 山田(副,金钱)
- 火奴鲁鲁：杰克(主,走廊暴力) + 布莱克(接手)

## 新增NTR角色扩展模式

当需要从6人扩展到9人时，新增角色应覆盖未被征服的阵营/类型：

| 新角色 | 身份 | 征服方式 | 覆盖阵营 |
|--------|------|----------|----------|
| 布莱克（马库斯部下） | 跟随者/协助者 | 跟随主角色+独立猎艳 | 被遗漏的配角 |
| 汉斯（铁血军医） | 科学家/医生 | 医疗检查+心智魔方改造 | 铁血系 |
| 维克多（东煌武术家） | 武术家/修行者 | 武道切磋+经络按摩+药物秘术 | 东煌/北联系 |

扩展原则：
1. 新角色必须覆盖原有角色未触及的阵营
2. 新角色的征服方式必须与现有角色有明显差异
3. 新角色应有独立的专属舰娘（至少2个）
4. 新角色可以是现有角色的部下/盟友，形成关系网

## 常见错误

### ❌ 错误1：只有一个NTR目标
- 所有开场白都围绕同一个角色
- 其他NTR目标只是"对照组"
- 结果：玩法单一，缺乏新鲜感

### ❌ 错误2：NTR目标没有独立剧情线
- 每个NTR目标只在世界书条目里提一下
- 没有独立的开场白和场景
- 结果：其他NTR目标形同虚设

### ❌ 错误3：NTR目标之间没有差异化
- 所有NTR目标都是"黑人+巨根"的模板
- 没有不同的身份、体型、征服方式
- 结果：千篇一律，缺乏特色

### ❌ 错误4：开场白不标注NTR目标
- 开场白里不知道当前是哪个NTR目标
- 玩家无法选择自己喜欢的NTR类型
- 结果：体验混乱
