# NTL逆寝取框架（{{user}}=寝取者）

## 何时使用
从NTR小说/世界观出发，制作**NTL（逆寝取）**角色卡。{{user}}不是原作苦主，而是**主动寝取别人爱人的人**。

## ⚠️ NTL vs 守护版（关键区分）
- **NTL（逆寝取）**：{{user}}=新角色，主动追求/征服NTR男性身边的女性。原作苦主是NPC。核心爽点=攻守逆转，"我来绿你"。
- **守护版/觉醒版**：{{user}}=原作苦主，觉醒后夺回自己的未婚妻。核心爽点=逆袭翻盘。
- 两者{{user}}身份完全不同，**不能混用同一条设计框架**。

## NTL版核心架构

### {{user}}身份设定
NTL版{{user}}必须有：
1. **独立身份**：不能是原作苦主，必须是新角色或原作中的NTR角色
2. **征服动机**：为什么要去寝取这些女性（欲望/野心/复仇/文化/本能）
3. **独特能力/资源**：支撑征服行为的硬实力（金钱/武力/法术/权力/魅力）
4. **性格层次**：不只是"色魔"，需要有让玩家代入的深度

### NTR男性→苦主NPC转化
原作中的NTR男性在NTL版中角色反转：
- 原NTR男性变成**苦主**——他们的女人被{{user}}抢走
- 保留原NTR男性的性格和势力，但地位从"征服者"变为"被征服者"
- 可以设计NTR男性发现{{user}}在寝取自己女人后的反应（愤怒/无力/崩溃）

### 女性角色定位
女性在NTL版中有三种可能定位：
1. **被{{user}}的魅力/能力征服**：主动选择{{user}}（纯NTL路线）
2. **从NTR男性手中被{{user}}"接管"**：先被NTR男性控制，然后{{user}}介入（NTL+救赎混合）
3. **同时周旋于NTR男性和{{user}}之间**：暧昧阶段，玩家的选择决定走向

### 征服升级链（替代NTR堕落链）
原版NTR有堕落链（正常→异常→沉沦→臣服），NTL版用**征服链**：

| Level | 名称 | 表现 |
|-------|------|------|
| 0 | 初遇 | {{user}}注意到目标女性，制定计划 |
| 1 | 接近 | 创造接触机会，展示实力/魅力 |
| 2 | 试探 | 小规模互动，测试底线 |
| 3 | 引诱 | 主动出击，突破防线 |
| 4 | 征服 | 目标女性沦陷 |
| 5 | 占有 | 公开或隐秘地将女性收入后宫 |

每级之间需要具体的**触发事件**推进（不能跳跃）。

### 苦主反应系统（NTL独有）
原作苦主（伯里等）在NTL版中作为NPC，有自己的反应系统：

| 阶段 | 苦主反应 | 触发条件 |
|------|---------|---------|
| 不知情 | 正常互动，偶尔疑虑 | {{user}}刚开始行动 |
| 隐约察觉 | 不安、追问、自欺 | 女性开始变化 |
| 亲眼目睹 | 愤怒/崩溃/无力 | {{user}}故意或意外暴露 |
| 接受/反抗 | 认命或暴力反击 | 关系公开化 |

## 开场白设计

NTL版开场白的关键差异：
- **视角**：{{user}}是主动方，不是被动旁观
- **基调**：充满自信和野心，展示{{user}}的实力/魅力
- **首幕**：{{user}}初到场景（小镇/城市/营地），发现目标女性和她们的"占有者"
- **暗示**：通过细节暗示{{user}}有能力也有意图去寝取

## 注意事项
- NTL版{{user}}不能是原作苦主——那是守护版
- 征服过程需要有**挑战性**，不能一键攻略
- 女性角色不能被简化为"物品"——她们有自己的意志和挣扎
- 苦主NPC的反应是NTL版的**核心戏剧张力来源**
- 征服手段要与{{user}}的身份/能力一致（赌场老板用金钱，兽人用暴力，法师用法术等）
