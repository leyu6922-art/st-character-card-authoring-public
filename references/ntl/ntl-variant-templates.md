## 模板十三：三层叠加阻力·挑战性设计（S级，P0）

兼容性：🟢 P0 纯文本通用
依赖项：无
冲突风险：无
降级方案：无需降级

### 适用场景
需要"有挑战性"的NTL/守护卡。多维度阻力确保不是无脑碾压。

### 设计理念
"不能太轻易夺回"需要三层独立阻力，而不是"NTR角色很强"这一条：
- 第一层·物理阻力：NTR强大（有弱点但不弱）
- 第二层·心理阻力：女主堕落深（有裂隙但惯性大）
- 第三层·感情阻力：女主对原配爱不够深（需要突破关系界限）

三层叠加意味着：不能只靠打败NTR来夺回。需要同时削弱NTR控制力+持续唤醒+突破感情界限。

### 条目模板
在全局规则/苦主体验条目中嵌入：

```
三层叠加阻力：

第一层·物理阻力：NTR角色强大
  - {角色A}：{强大点}。弱点：{弱点}
  - {角色B}：{强大点}。弱点：{弱点}

第二层·心理阻力：女主堕落深
  - 异常期：隐瞒+否认
  - 沉沦期：开始享受，对原配不耐烦
  - 臣服期：主动为NTR辩护甚至敌视原配

第三层·感情阻力：女主对原配爱得不够深
  - {角色A}：{关系类型}→难度★★★★★
  - {角色B}：{关系类型}→难度★★★★
  - {角色C}：{关系类型}→难度★★★
```

### Pitfalls
- 三层不能同时满强度（否则玩家无法推进）
- 建议节奏：前期物理为主→中期心理为主→后期感情为主
- 每层都必须有对应的破解手段

## 模板十四：NTR升级链·从原著提炼（M级，P0）

兼容性：🟢 P0 纯文本通用
依赖项：无
冲突风险：无
降级方案：无需降级

### 适用场景
有丰富原著素材的NTR/NTL卡。NTR不是一步到位，而是有Level的逐步过程。

### 设计理念
每个Level都是一个叙事节拍，必须从原著提炼（不能凭空编造）。NTL版在每个Level设计对应的打断手段。

### 条目模板
在每个女主的角色档案中嵌入：

```
{角色名}·被NTR的详细过程：
  Level 0·试探接触：{初始接触场景}
  Level 1·初步得手：{第一次深度接触}
  Level 2·沉沦加深：{开始习惯/享受}
  Level 3·彻底征服：{完全臣服}
  Level 4·公开化：{在原配面前展示}
  Level 5·常态化：{成为日常}

每个Level配：
  - 场景描写（从原著提取）
  - 关键对话（从原著提取）
  - 触发条件（Level N→N+1的条件）

NTL打断手段（每个Level对应一种）：
  Level 0→打断：{干预方式}
  Level 1→打断：{干预方式}
  ...
```

### Pitfalls
- 必须从原著提炼，不能凭空编造
- Level之间要有明确触发条件（不是自动升级）
- NTL版必须在每个Level设计打断手段

## 模板十五：NTR角色弱点+反转行为（M级，P0）

兼容性：🟢 P0 纯文本通用
依赖项：无
冲突风险：无
降级方案：无需降级

### 适用场景
有多个NTR角色的NTL卡。每个NTR有具体弱点+被击败后的独特反应（剧情亮点）。

### 条目模板
在NPC自主行动条目中追加：

```
【NTR角色弱点系统】
- {角色A}弱点：①{弱点1} ②{弱点2} ③{弱点3} ④{弱点4}
- {角色B}弱点：①{弱点1} ②{弱点2} ③{弱点3}

【被反转后行为】
- {角色A}被{道具}后：{反应描述}（剧情亮点）
- {角色B}被{道具}后：{反应描述}（剧情亮点）

【NPC被削弱机制】
每个NTR有"控制力"(0-100)。
- 控制力100-80：NTR完全掌控，行动肆无忌惮
- 控制力80-50：NTR开始察觉异常，行动更谨慎
- 控制力50-20：NTR慌张，加强控制（反弹更强）
- 控制力20-0：女主进入可唤醒状态
- 控制力=0：NTR彻底失败，可施加反转道具
```
