### T61: 小说预处理·文件名含标题后缀（2026-07-14·医生妈妈叶明熙卡实证）

**症状**：章节文件名格式不统一——部分文件名为"第25章.txt"，部分为"第25章 诊室调戏弄美母.txt"。按固定模式`f"第{ch:02d}章.txt"`读取时，含标题后缀的文件读出0字节（文件不存在）。

**实测数据**（医生妈妈叶明熙，38章）：
- 前20章：文件名格式统一"第XX章.txt"→正常读取
- 第21-38章：文件名含标题后缀"第XX章 标题名.txt"→固定模式匹配失败→返回0字

**修复**：用`os.listdir()`发现实际文件名，不要假设命名格式：
```python
files = os.listdir(base)
matching = [f for f in files if f.startswith(f"第{ch:02d}章") or f.startswith(f"第{ch}章")]
if matching:
    fp = os.path.join(base, matching[0])
```

**验证方法**：读取后检查字数，0字的条目立即重新搜索匹配。

### T62: 场景条目合并后constant+keys冲突（2026-07-14·医生妈妈叶明熙卡实证）

**症状**：多个薄场景条目（各自<300字）合并为1个综合场景条目后，设`constant=True`但保留了`keys=["病房","诊室",...]`→validate_card check26报错"常驻条目必须keys=[]"。

**根因**：合并时从3个trigger条目（各自有keys）合为1个constant条目，忘记清空keys。

**修复**：
- 合并场景条目如需常驻(constant=True)→keys必须清空为[]
- 如需关键词触发→设constant=False并保留keys
- 合并后立即检查：`if e['constant'] and e['keys']: fix`

### T64: 事件种子感官细节扩充法（2026-07-14·医生妈妈叶明熙卡实证）

**症状**：事件种子（enabled=false）字数不足（176-240字 vs 建议≥300）。重新撰写整条效率低。

**高效修复**：在每条种子末尾追加"【感官细节】"段落，同时提升字数和内容质量：
```
【感官细节】此场景中的核心感官刺激需要在展开时充分体现——
```

**适用范围**：种子字数<300且≥150（绝对底线以上）。如果<150则需要重写整条。

### T65: 描写库追加导致重复段标题（2026-07-14·医生妈妈叶明熙卡实证）

**症状**：描写库content用`+=`追加到角色条目时，`【身体描写·日常】`、`【感官描写】`等标题与原条目中的同名标题重复→审查脚本`re.findall(r'【(.+?)】')`报"条目内重复段"。3个角色条目各2-5个重复。

**根因**：描写库作为独立content写入时标题自成体系，追加到已有角色条目后标题冲突。

**修复**：追加前重命名描写库中的section headers：
```python
desc_part = desc_part.replace("【身体描写", "【详细身体描写")
desc_part = desc_part.replace("【感官描写", "【详细感官描写")
desc_part = desc_part.replace("【场景反应差异", "【补充场景反应")
content = original + "\n\n【附·描写库】\n" + desc_part
```

**验证**：合并后`re.findall(r'【(.+?)】', content)`检查零重复标题。
