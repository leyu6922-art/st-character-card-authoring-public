# 分段标记：大型卡组织工作流

> 源自：大型结构化卡 v4.2 的 `➡️` 分段系统
> 兼容性：P0 纯文本通用
> 相关模板：模板十五「事件分段标记」

---

## 一、核心概念

对于 50+ 条目的大型卡，在条目序列中插入**空条目分段标记**（`➡️` 标记），将条目分为逻辑块。标记条目 `keys=[]`, `constant=true`，内容为空或仅含标记文本。

---

## 二、标准分区模板

### NTR/NSFW 卡的标准分区

```
[条目1-8]   ➡️系统区开始 → OOC/文风/状态栏/机制/逻辑防火墙 → ➡️系统区结束
[条目9-15]  ➡️角色区开始 → {女主A}/{女主B}/{苦主}... → ➡️角色区结束
[条目16-22] ➡️关系区开始 → NTR关系矩阵/{女主}×{NTR对象} → ➡️关系区结束
[条目23-30] ➡️场景区开始 → 家/学校/酒吧/温泉/酒店 → ➡️场景区结束
[条目31-45] ➡️事件区开始 → 事件种子库 → ➡️事件区结束
[条目46-52] ➡️NTR目标区开始 → {NTR对象A}/{NTR对象B}... → ➡️NTR目标区结束
[条目53-55] ➡️扩展区开始 → DLC场景/随机池/备用 → ➡️扩展区结束
```

### 冒险/TRPG 卡的标准分区

```
[条目1-15]   ➡️系统区 → 规则引擎/变量/状态/输出格式
[条目16-45]  ➡️世界观区 → 设定/历史/种族/势力
[条目46-270] ➡️地点区 → 地点条目（按国家/区域分组）
[条目271-300] ➡️DLC区 → DLC事件/扩展/角色
[条目301-310] ➡️功能扩展 → 抽卡/面板/快捷功能
```

## 三、标记条目的 JSON 格式

```json
{
  "id": XX,
  "comment": "➡️角色区开始",
  "keys": [],
  "content": "",
  "constant": true,
  "enabled": true,
  "position": "before_char",
  "extensions": {
    "position": 0,
    "excludeRecursion": true,
    "displayIndex": XX,
    "probability": 100
  }
}
```

**关键字段说明：**
- `keys: []` — 无触发词，不会被关键词触发
- `constant: true` — 始终可见，在ST编辑器中也显示
- `content: ""` — 空内容，零token成本
- `comment` — 在ST的条目列表中可见，作为视觉分隔标识

---

## 四、标记条目的 displayIndex 规划

在ST编辑器中，条目按 `displayIndex` 排序。合理规划索引让编辑和调试更容易：

| 分区 | displayIndex 范围 | 条目数 |
|------|------------------|--------|
| 系统区 | 0-15 | ~8 |
| 角色区 | 100-199 | ~15 |
| 关系区 | 200-299 | ~10 |
| 场景区 | 300-399 | ~10 |
| 事件区 | 400-499 | ~15 |
| NTR目标区 | 500-599 | ~10 |
| 扩展区 | 600-699 | ~5 |

**收益**：在ST编辑器中有"隔断"效果，不同分区的条目自然分离。

## 五、批量启用/禁用

有了分段标记后，可以按区批量操作：

### 场景一：测试新NTR对象

```
禁用：➡️NTR目标区（保留旧对象）
启用：➡️扩展区（新对象放在扩展区）
结果：只测试新对象的影响，旧对象暂时不触发
```

### 场景二：压力测试

```
全部禁用除了：➡️系统区 + ➡️角色区 + ➡️场景区
结果：只跑基础系统，测量纯token负载
```

### 场景三：快速切换事件集

```
启用：➡️事件区·轻口味
禁用：➡️事件区·重口味
结果：根据场合快速切换事件口味
```

## 六、Pitfalls

> ❌ `constant: false` → ST中看不到标记，失去了"组织"的作用
> ❌ 标记条的 comment 写成中文描述性文本 → 浪费（ST中comment行的空间有限）
> ✅ 标记条用简洁的emoji+分区名 → `➡️角色区开始`
> ✅ 标记条 keys=[] constant=true → 始终可见且不干扰触发
> ✅ displayIndex 用大间隔（100/200/300...）→ 插入新条目不需要重新编号
