# 小说→角色卡 预估分析流程

在正式写卡前，先用此流程预估卡的规模，避免做大了膨胀或做小了遗漏。

## 第一步：抓取+基础数据

1. 抓取全部章节到本地（参考 web-novel-scraper skill）
2. 统计：总章节数、实际总字数（alicesw 标称字数常虚标 1.5-2x，以实际提取为准）
3. 按卷/阶段划分章节区间

## 第二步：角色出场频次扫描

用正则扫描全部文本中每个角色名的出现次数，识别：
- 核心女主（出场300+次 → 需要最厚的条目）
- 重要配角（100-300次 → 中等厚度）
- 边缘角色（50-100次 → 轻量条目或合并）
- 路人级（<50次 → 考虑是否入卡）

```python
import os, re
from collections import Counter

d = "/path/to/novel_chapters"
all_text = ""
for f in sorted(os.listdir(d)):
    with open(os.path.join(d, f), encoding='utf-8') as fh:
        all_text += fh.read()

# 已知角色名列表（从阅读中提取）
known_chars = {"角色A": 0, "角色B": 0, ...}
for name in known_chars:
    known_chars[name] = len(re.findall(name, all_text))

for name, count in sorted(known_chars.items(), key=lambda x: -x[1]):
    print(f"  {name}: {count}次")
```

## 第三步：剧情结构分析

阅读首章、中间转折章、末章，提取：
- 叙述视角（第一人称苦主 / 第三人称上帝 / 多视角）
- 剧情阶段数（如：发现期→沉沦期→扩展期→终局）
- 每阶段的核心场景和新引入角色
- 主题标签（公厕化/会所/直播/催眠/洗脑等）

## 第四步：对标已有卡的基准

| 参考基准 | 小说字数 | 角色数 | 条目数 | 大小 |
|---------|---------|--------|--------|------|
| 交配学校 | 4.7万 | 7 | 25 | 108KB |
| 示例角色项目 | 10.8万 | ~6 | 33 | 149KB |
| 圣馨医院 | 9万 | ~8 | 40 | 210KB |
| 堕绿仙家 | 16.3万 | ~8 | 43 | ~200KB |
| 抵受不住亲姐姐 | 长篇108章 | ~8 | 68 | 222KB |
| 人妻妈妈娼馆 | 23万 | ~8 | 45 | 182KB |

关键规律：
- **条目数主要取决于角色数量**，不是小说字数
- **单条目大小取决于素材密度**（原文越长，对话引用和行为模板越丰富）
- **世界观复杂度是隐形变量**（仙侠体系 >> 现代都市）
- 小说字数 → 影响单条目素材丰富度；角色数量 → 决定条目总数
- 角色数量的权重高于字数
- **短篇小说（<5万字）的卡大小主要受条目数驱动**：47K字+7角色→25条→108KB（条目结构开销占比高），而不是内容字数驱动。短篇卡的每个条目必须更充实（从原文提取对话+行为模板），否则总内容字数不够撑起条目

## 第五步：输出预估

综合以上分析，给出：
1. 预估条目数范围（如 55-65 条）
2. 预估大小范围（如 200-260KB）
3. 最接近的参考卡（如"接近人妻妈妈娼馆"）
4. 卡的特殊挑战（如"女主一人撑1249次提及，需要极厚的行为模板条目"）

## 案例：新婚妻子-NTR

- 29章/4卷/26.5万字
- 核心女主芷姗1249次，5女性+5男性+丈夫
- 现代都市无复杂世界观，但场景密度高（公厕/会所/网站/公司/公园）
- 预估：55-65条/200-260KB，接近人妻妈妈娼馆但芷姗条目更厚

## 案例：示例角色项目被绿的异世界冒险（2026-07-10）

- 52章/55万字，异世界NTR
- 角色频次：师傅3729次、伯里2965次、伊丝娜1647次、爱德1351次、奥萝拉1216次、妮丝449次
- 4女（师傅/伊丝娜/奥萝拉/妮丝）×5男（爱德/黑巨汉/肥猪领主/黑兽人/练武场壮汉）
- 最终：33条/200.1KB/44,896 content chars/8常驻+25触发/6开场白
- **文件大小倍率：4.5x**（44K content chars → 200KB file）
- 特殊挑战：55万字素材需子代理分3段并行分析；"萝莉"违禁词30+处需替换；4女×5男=20条关系线需合并为独立角色条目+阶段特征库
- 多轮扩充模式：框架115KB→扩充角色127KB→扩充系统/事件141KB→扩展开场白151KB→扩充薄条目164KB→继续扩充172KB→补充对话库190KB→最终200KB（6轮扩充）
- 违禁词替换策略：萝莉肥臀→娇小肥臀，肥臀萝莉→肥臀少女，萝莉→少女（catch-all）
