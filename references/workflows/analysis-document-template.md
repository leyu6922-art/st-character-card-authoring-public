# 小说分析文档模板 — 跨窗口交接件

当小说规模>30章或>20万字时，一个窗口无法完成从读到写的全部工作。需要这个窗口产出分析文档，另一个窗口据此构建角色卡。本文档是分析文档的标准结构模板。

## 用途
- 读卡窗口输出此文档 → 写卡窗口读取此文档开始构建
- 确保跨窗口信息不遗漏
- 包含写卡窗口需要的全部关键信息（角色/机制/事件/做卡建议）

## 模板结构

## 产出文档的质量标准

| 维度 | 要求 |
|------|------|
| 角色覆盖度 | 所有核心角色必须包含外貌/身份/关键事件三要素 |
| 机制提取 | 任何可复用的系统/规则必须单独列出描述 |
| 事件覆盖度 | 每个故事阶段至少2-3个关键事件记录 |
| 做卡建议 | 必须包含原型建议+时间节点+条目规划 |
| 总字数 | ≥15KB（10章小说）~30KB（100+章小说） |
