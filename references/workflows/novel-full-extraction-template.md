# 小说全方位预处理提取模板

> 来源：《艳母的荒唐赌约》(120章/158万字) 提取实战验证 (2026-07-17)
> 用途：大中型小说的结构化预处理，产出供另一窗口直接做卡的分析文档

## 何时使用

- 小说 ≥ 20章 或 ≥ 20万字
- 用户要求"全方位提取"/"预处理"/"分析文档"
- 需要跨窗口交接（一个窗口读+分析，另一个窗口做卡）

## 与 analysis-document-template.md 的区别

| 维度 | analysis-document-template | 本模板 |
|------|--------------------------|--------|
| 定位 | 轻量交接件（快速概览+关键事实） | 深度提取（10大维度全覆盖） |
| 角色档案 | 基础表格（姓名/身份/外貌/事件） | 完整六维+语言指纹+行为模板+对话样本 |
| 行为语料 | 无 | 情绪/互动/外貌/环境四类语料库 |
| 场景库 | 无 | 每个场景7要素提取 |
| 叙事风格 | 无 | 视角/文风/技巧/风格样本 |
| NSFW场景 | 无 | 逐场景参与者/行为链/情感状态/关键描写 |
| 目标字数 | 15-30KB | 20-40KB |

**选择建议**：< 30章用 analysis-document-template，≥ 30章或需要深度做卡用本模板。

## 10大提取维度

### 第一部分：基础统计
- 章节数、总字数/中文字数、平均每章字数
- 目录结构（已拆分/需拆分/合集大txt）
- 编码检测顺序：utf-8-sig → utf-8 → gb18030
- 重复文件检测（按文件大小分组）

### 第二部分：世界观与背景
- 时代与地点（每个地点：名称/功能/氛围/出现章节）
- 核心设定与机制（A/B/C级权重评级）
- 社会制度与禁忌

### 第三部分：人物全方位档案
**角色挖掘方法**（5步，详见 chinese-novel-character-extraction.md）：
1. 开头段落扫描（每章前30行）
2. 三字名模式搜索（`姓氏[一-龥]{1,2}` + 非名过滤）
3. 对话归属验证（`人名+说/道/笑/喊/叫/叹/怒/冷/微/沉/皱`）
4. 章节分布验证（跨3+章=真实角色）
5. 别名归并

**核心角色档案模板**（频次TOP5或贯穿全文）：
```
基础信息：身份/年龄外貌/性格关键词/社会地位
性格六维：公开人设/私下真实/核心欲望/核心恐惧/道德底线/性格弱点
语言指纹：称呼习惯/口头禅(原文+章节)/语气特征/对话样本(5-10句)
行为模板：日常行为/情绪反应/社交行为/性相关行为/关键行为链
关系网络：逐人记录关系类型/情感状态/关键事件/演变轨迹
出场章节表：章节/出场类型/重要事件
角色弧线：起点→转折→终点
```

**重要角色**（频次TOP6-15）：精简档案（基础信息+语言指纹+3个行为模板）
**轻量角色**（频次<15但有剧情功能）：一句话描述+关键行为

### 第四部分：关系矩阵
- 血缘/家庭关系图
- 情感关系矩阵（角色A/角色B/关系类型/情感深度1-5/关键事件/演变方向）
- 权力/控制关系（控制方/被控方/控制手段/强度/章节）
- 对立/冲突关系

### 第五部分：场景库
每个场景7要素：地点/氛围(感官描写)/功能/关联角色/关联事件/叙事道具/出现章节

### 第六部分：事件时间线
每章至少2-3个事件，每个记录：参与者/触发条件/过程(100-200字)/结果/情感基调

### 第七部分：行为语料库（最关键维度）
从原文直接提取可被AI复用的行为描写：
- **情绪描写语料**：愤怒/屈辱/欲望/恐惧/喜悦/矛盾，每种≥3条原文
- **互动行为语料**：争吵/亲密/服从/反抗/妥协，含参与角色
- **外貌/身体描写语料**：按角色归档，区分整体/局部
- **环境/氛围描写语料**：按场景类型分类（夜晚/室内/户外）

### 第八部分：叙事风格分析
- 叙事视角（第几人称/跟随谁/切换模式）
- 文风特征（用词/句式/修辞/节奏）
- 叙事技巧（悬念/伏笔/时间线/多线）
- 风格样本（2-3段代表性原文，每段100-200字）

### 第九部分：NSFW场景目录（如有）
每个场景：参与者/地点/触发前因/行为概述(具体行为链)/情感状态/关键描写原文(2-3句)/关系变化

### 第十部分：做卡建议
- 卡片原型建议（适配度★评级+理由）
- {{user}}身份建议（推荐+备选+各自优劣）
- 时间节点建议（好处/坏处/推荐度）
- 条目规划预估（类别/条目数/每条字数目标）
- 需人工确认的设计决策
- 后续窗口需补充精读的章节

## 并行子代理读取策略（120+章）

当小说超过80章时，用 `delegate_task` 并行读取：

```python
# 3个子代理分别处理不同章节范围
delegate_task(tasks=[
    {"goal": "读取第1-40章，提取角色/事件/对白/描写", "context": "..."},
    {"goal": "读取第41-80章，提取角色/事件/对白/描写", "context": "..."},
    {"goal": "读取第81-120章，提取角色/事件/对白/描写", "context": "..."},
])
```

**同时**主代理自己读取前20章（精读），因为前几章的角色介绍和世界观设定最重要。

**context中必须包含**：
- 已知角色名和基本身份（避免子代理重复发现）
- 小说目录路径
- 输出格式要求（中文报告）

**子代理产出**：各章的角色/事件/对白/描写摘要（中文）
**主代理职责**：综合子代理产出 + 自己的精读结果 → 写入最终文档

for enc in ['utf-8-sig', 'utf-8', 'gb18030']:
    try:
        with open(path, 'r', encoding=enc) as f:

        break

matches = pat.findall(all_text)

## 质量标准

| 维度 | 要求 |
|------|------|
| 角色覆盖度 | 核心角色完整档案（含语言指纹+行为模板），重要角色精简档案 |
| 对白语料 | 核心角色每人 ≥10 句原文对话 |
| 行为语料 | 每个情绪类型 ≥3 条原文描写 |
| 关系覆盖度 | 所有重要两两关系都有记录 |
| 事件覆盖度 | 每章 ≥2 个关键事件 |
| 场景覆盖度 | 所有重复出现的场景都有记录 |
| 风格样本 | ≥3 段代表性原文段落 |
