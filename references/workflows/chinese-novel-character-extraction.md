# 中文小说角色名提取方法论

> 从纯文本小说中系统性提取角色名、频次、关系。用于 §2.4 小说预处理阶段。

## 方法一：单字姓氏频次扫描（初筛）

用常见姓氏列表在全文中做单字搜索，快速定位哪些姓氏高频出现。

**适用场景**：小说无角色表、无明确人名索引、需要从零发现人物。

```python
surnames = ['雷','萧','高','白','孟','谭','叶','林','秦','任','马','方','许','谢',
            '唐','金','陆','孔','段','常','钟','程','顾','石','戴','龙','万','毛',
            '易','田','汪','杜','范','武','文','熊','朱','胡','孙','梁','曾','余',
            '钱','傅','沈','苏','卢','阎','姚','廖','邹','崔','康','邱','江','史',
            '侯','邵','贺','赖','龚','宋','郑','韩','冯','于','董','蔡','彭','潘',
            '袁','蒋','邓','罗','何','周','吴','徐','李','王','张','刘','陈','杨',
            '赵','黄']

for surname in surnames:
    count = all_text.count(surname)
    if count >= 10:
        print(f"{surname}: {count}次")
```

**⚠️ 假阳性陷阱**：单字姓氏搜索会产生大量假阳性：
- `高` → 高潮/高耸/高大/高级/高声/高跟鞋
- `白` → 白皙/白嫩/白天/白衣/白发
- `雷` → 雷声/雷光/雷电/雷鸣/雷霆/雷劫
- `于` → 于是/于她/于那
- `方` → 方才/方面/方向/方式/方圆
- `马` → 马上/马赛克/马路
- `任` → 任由/任何/任务/任命
- `叶` → 叶城/叶倩（这两个是真名，但也可能匹配叶府/叶子）
- `龙` → 龙卷
- `曾` → 曾经
- `毛` → 毛骨/毛发
- `石` → 石破
- `文` → 文章/文化
- `白` → 白皙的/白嫩的

**结论**：单字频次只能做初筛信号，不能直接认定为角色名。必须结合方法二验证。

## 方法二：三字名模式搜索（主方法）

## 方法三：对话归属模式提取（验证+补充）

搜索 `人名 + 说/道/笑/喊/叫/看/点/叹/怒/冷/微/沉/皱` 模式，验证方法二发现的名字确实是说话主体。

```python
dialogue_names = re.findall(
    r'([\u4e00-\u9fff]{2,4})(?:说|道|喊|叫道|笑道|喊道|问道|叹道|怒道|冷笑|微笑|苦笑|'
    r'看着|点了点头|叹了口气|沉默|皱眉|回答|回应|开口|轻声|低声|大声|突然|冷冷|淡淡)',
    all_text
)
name_freq = Counter(dialogue_names)

# 排除停用词（非常长的列表，含动作/状态/情感/方位等常见词）
stopwords = {'她', '他', '自己', '什么', '怎么', '这个', '那个', ...}  # 见下方完整列表
```

**⚠️ 此方法的局限**：
- 中文小说中角色不一定每句都有对话归属（尤其是第一人称叙述）
- 很多非人名的动词/形容词也会匹配（"不知说"/"突然说"）
- 适合验证已有名字，不适合作为唯一发现手段

## 方法四：章节分布验证（最终确认）

对每个候选名字，统计在各章节中的分布：

```python
for name in candidate_names:
    ch_hits = []
    for fname, content in chapters.items():
        c = content.count(name)
        if c > 0:
            ch_hits.append(f"{fname}({c})")
    print(f"{name}: {all_text.count(name)}次 | 分布: {', '.join(ch_hits)}")
```

**判断标准**：
- 跨3+章节出现 → 高概率真实角色
- 集中在1-2章 → 可能是配角或一次性NPC
- 首次出现的上下文含身份描述 → 可确认为角色

## 方法五：开头段落直接读取（最可靠）

直接读取每章开头20-50行，通常包含：
- 角色自述/介绍
- 系统面板（如有）
- 场景描述中的角色名
- 对话开头的角色互动

```python
for fname in sorted(chapters.keys()):
    lines = chapters[fname].split('\n')
    for i, line in enumerate(lines[:30]):
        if line.strip():
            print(f"  [{i}] {line.strip()[:150]}")
```

## 推荐组合流程

1. **方法五**：先读第1章开头30行，快速获取主角名和设定
2. **方法一**：单字姓氏频次初筛，标记高频姓氏
3. **方法二**：三字名模式搜索，获取候选名字列表
4. **方法四**：章节分布验证，确认真实角色
5. **方法三**：对话归属验证，补充遗漏

## 🆕 方法六：简化的对话归属模式（2026-07-17验证，120章/158万字实战）

比方法三更简单但更有效的模式——只搜`人名+单字动词`：

```python
pat = re.compile(r'([\u4e00-\u9fff]{2,3})(?:说|道|笑|喊|叫|叹|怒|问|答|想|骂|哭|走|跑|站|坐|听)')
matches = pat.findall(all_text)
counts = Counter(matches)
```

**优势**：比多动词组合模式更简洁，假阳性更少。在《艳母的荒唐赌约》中正确识别出全部6个核心角色。
**局限**：需要手动过滤"不知/也不知/谁知/忍不住/不得不"等高频非人名组合。

## 角色名混淆预警模板

搜索完成后，按以下维度检查混淆风险：

| 维度 | 检查方法 | 示例 |
|------|----------|------|
| 同姓家族 | 搜索同一姓氏的所有高频名字 | 萧凝馨/萧凝璇/萧诺 |
| 同音/近音 | 手动检查读音相近的名字 | 叶城/叶凌（城≠凌但都是叶姓） |
| 重生/改名 | 搜索"原名/曾用名/重生"关键词 | 叶震→雷震、叶凌→雷凌 |
| 称谓重叠 | 检查同一人是否有多个称呼 | 秦韵/秦盟主/韵奴/乾元女帝 |
| 母女不同姓 | 确认母女关系（可能随父姓不同） | 谭颖/孟紫然（母女但不同姓） |
| 亲属词裸写 | 全文搜索"妈妈/妹妹/父亲"等裸亲属词 | "妈妈"可能指秦韵也可能泛指 |

- 方法四验证：雷纵在8/10个文件中出现，萧凝馨在7/10个文件中出现
