# 模板库评估工作流（2026-07-10 交配学校案例）

## 何时使用
写规划书之前，必须先完成模板评估。此文档提供系统化的评估方法。

## 评估流程

### Step 1: 读取模板库
```python
# 在 skill_view 中读取
# references/game-mechanics-template-library.md → 19个模板
```

### Step 2: 小说特征提取
从小说全文中提取以下特征（用于对照模板）：

| 特征维度 | 提取方法 | 示例 |
|---------|---------|------|
| NTR类型 | 分析控制手段 | 肉体征服/灵魂操控/经济胁迫/身份便利 |
| 超自然元素 | 搜索关键词 | 恶魔相机/催眠/系统面板/无 |
| 进度追踪 | 分析是否有量化指标 | 淫纹数字/堕落度0-100/好感度 |
| 风险机制 | 是否有"被发现"风险 | NTR题材有/合法行为无 |
| 角色阶段变化 | 同一角色不同阶段行为是否不同 | 苏淑歆四阶段/金圣婉痴迷度 |
| NPC数量 | 独立行动逻辑的NPC数 | 3+个NPC适合用NPC自主行动模板 |
| 剧情节点 | 是否有多个可选场景 | 入职/课堂/家访/考试 |
| 特殊系统 | 是否有需要解释的机制 | 淫纹系统/交配9步流程/圣母教会 |

### Step 3: 逐模板对照
对19个模板逐一判断适用性，输出表格：

```markdown
| 模板 | 适用？ | 理由 |
|------|--------|------|
| 状态栏系统 | ✅ | 所有卡必须用 |
| 好感度/堕落度 | ✅ | 苏淑歆四阶段堕落 |
| 事件种子库 | ✅ | 6个关键剧情节点 |
| NPC自主行动 | ✅ | 三女教师各自有主动逻辑 |
| 旁白解说 | ✅ | 淫纹系统/交配9步需要解释 |
| 多阶段开场白 | ✅ | 从不同时间点切入 |
| 阶段行为特征库 | ✅ | 苏淑歆各阶段行为差异大 |
| 变量追踪 | ❌ | 淫纹数字=天然进度，不需脚本 |
| 风险检测 | ❌ | 教师交配是合法的，无被发现风险 |
| 心理操控 | ❌ | 金圣婉痴迷是自然吸引非操控 |
| 道具进化 | ❌ | 无超自然道具 |
| BAD END | ❌ | 基调轻松愉快 |
```

### Step 4: 融入规划书
将采用的模板直接体现在条目规划中：
- 系统条目引用模板名称（如"状态栏模板（模板一）"）
- NPC自主行动表直接用模板五的格式
- 堕落阶段直接用模板二的阶段划分格式

## 典型案例

### 交配学校（2026-07-10）
- 47K字/9章，玩法型世界观
- 7个模板适用（全部P0），5个不适用
- 核心发现：淫纹系统是天然进度追踪，不需要变量脚本（P3）
- 规划书v1没做模板审查→v2补上后条目架构更清晰

### 示例玄幻项目
- 36万字/长篇，灵魂操控型NTR
- 使用模板三（变量追踪，P3）+ 大部分P0模板
- 核心发现：恶魔相机系统需要道具进化模板+副作用系统

### 示例游戏项目港区后宫
- 短篇+游戏IP，多NTR目标
- 使用模板六（风险检测）+ 事件种子库
- 核心发现：已知IP角色需要外貌验证

## Pitfalls

1. **不要跳过评估直接写规划书** — 模板选择改变条目架构，事后补改代价大
2. **P3模板慎用** — 大多数预设MVU OFF，变量系统会成为死代码
3. **一个模板不适用≠不需要该机制** — 如BAD END不适用但可以用种子库代替
4. **模板可组合** — 状态栏+堕落度+NPC行动+旁白 = 完整游戏机制
