## 1. 确认卡类型与世界观
从 system_prompt 和计划书中提取：
- {{user}}=谁？身份和年龄？（儿子/外甥/学生？）
- 几个核心女主？各自的公开身份（官员/老师/贵妇）和私下身份？
- "禁忌"的来源是什么？（母子/姨甥/师生/上下级？）
- 有没有"背景板"角色（如父亲/丈夫）提供禁忌张力？

**输出关系矩阵**（女 × 公开身份/私下身份/关系类型），这是后续检查的基准。

## 2. 保密系统闭环检查（E型核心！）
搜索"保密""公开""私下""模式""切换""暴露""安全等级"等关键词。确认：

| 检查项 | 要求 |
|--------|------|
| 保密铁律条目 | 是否有专门的保密规则常驻条目（或嵌入OOC条目）？ |
| 公开/私下切换 | 是否定义了从公开模式切换到私下模式的条件？（锁门/确认无人/确认父亲不在） |
| 安全等级 | 每个场景是否定义了安全等级（S=绝对私密/A=低风险/B=有风险/C=公开场合）？ |
| 暴露后果 | 是否描述了泄密的代价（政治生命终结/家庭破裂）？ |
| 背景板触发 | 父亲/丈夫偶尔在家的场景是否有专门处理规则？ |

**保密是E型卡的第一原则。** 没有保密系统=所有女主随时可能被AI写成公开秀恩爱=世界观崩塌。
```python
# 检查保密系统覆盖
secrecy_keywords = ['保密', '公开', '私下', '模式', '切换', '暴露', '安全等级', '锁门']
for kw in secrecy_keywords:
    found = any(kw in e.get('content','') or kw in e.get('comment','') for e in entries)
    if not found:
        print(f"🟡 关键词'{kw}'未在任何条目中找到")
```

## 3. 公开/私下双模式完整性
逐女主检查——每个女主是否有两种行为模板：

| 女主 | 公开模式 | 私下模式 | 切换触发条件 |
|------|---------|---------|-------------|
| [女主1] | 公开身份/称呼/语气/着装 | 私下身份/称呼/语气/着装 | 何时切换？ |
| ... | ... | ... | ... |

**检查要点**：
- 称呼切换是否有明确规则？（公开叫"妈"→私下叫"楠楠"）
- 切换过渡是否合理？（不是瞬间翻脸，而是确认安全→锁门→第一句暧昧→完全切换）
- 是否所有场景条目中都标注了"当前可用的模式"？

**常见问题**：女主在公开场合被AI写出私下模式的言行——因为没有定义切换触发条件。

## 4. 权力反差描写检查
核心爽点：社会地位越高的女人，私下反差越强烈。

- system_prompt 是否强调了权力反差？（"她是政法委书记，但私下叫你老公"）
- 每个女主的档案中是否同时描写了"公开的威严"和"私下的淫荡"？
- 旁白是否会在关键时刻提示反差？（如"刚才在会议上雷厉风行的倪书记，此刻正趴在你的膝上..."）

**常见问题**：只写了私下的淫荡面，没写公开的威严面→权力反差失效，变成普通后宫。

## 5. 场景安全等级一致性
逐场景检查：

| 场景 | 安全等级 | 允许的互动 | 风险因素 |
|------|---------|-----------|---------|
| [场景1] | S/A/B/C | 可全裸/可调情/只能眉目传情/完全公开 | 谁可能突然出现？ |

**检查要点**：
- 安全等级是否定义了每种等级下"可以做什么/不能做什么"？
- 同一安全等级在不同场景条目中的规则是否一致？
- 是否有"安全等级跃迁"机制？（如"办公室锁门后 B→A"）
- 风险因素（父亲回家/突然敲门/同事撞见）是否在各场景中有对应处理？

## 6. 多女主协调机制
- 是否有多女共处的规则条目？（后宫互动总则/姐妹共侍规则）
- 女主之间的互动（吃醋/配合/竞争）是否有描写？
- 状态栏是否同时追踪多位女主的独立状态？
- 每位女主是否有独立的征服阶段（不是所有人同步）？

**常见问题**：多位女主被写成同一模板——"X也是你的女人，也私下叫你老公"。每个应有独特的互动模式。

## 7. 反AI顺从检查（E型专用）
E型卡中反顺从的重点不同于NTR：
- 女主拒绝的主要理由不是"我不能背叛丈夫"，而是"太危险了/会暴露/你爸在家"
- 拒绝策略应体现女主的顾虑层次：先评估安全→再考虑意愿
- {{user}}不能"瞬移"到私密空间——场景切换需要合理过渡

```python
# 检查反顺从条目中是否包含保密相关拒绝理由
anti_comply_content = [e for e in entries if '反AI' in e.get('comment','') or '反顺从' in e.get('comment','')]
for e in anti_comply_content:
    if '暴露' not in e.get('content','') and '保密' not in e.get('content',''):
        print(f"🟡 ID{e['id']}: 反顺从条目未提及保密/暴露相关拒绝理由")
```

## 8. 输出审查报告
按🔴关键/🟡重要/🟢优化三级。E型卡专属关注点：
- 保密系统是否闭环（定义→触发→切换→暴露后果）
- 公开/私下双模式是否每个女主都有且一致
- 权力反差描写是否到位（公开威严+私下反差）
- 场景安全等级是否覆盖所有场景且规则一致
- 多女主协调机制是否存在
