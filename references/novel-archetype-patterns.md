# 小说原型→模板组合指南（Novel Archetype → Template Combination）

> 不同类型的小说适合不同的模板组合。本文档记录已验证的原型-模板映射，避免每次重新评估。

## 原型一：系统/游戏流（System Novel）

**特征**：男主有系统面板、数值（好感/堕落/等级）、商城兑换、任务列表、能力升级。
**代表作**：万恶后宫系统（43万字）

### 推荐模板组合（全P0）

| 模板 | 用途 | 必要性 |
|------|------|--------|
| 一·状态栏 | 系统面板实时显示（万恶值/等级/属性） | ⭐必选 |
| 二·好感度/堕落度 | 系统自带的沦陷值/好感度映射 | ⭐必选 |
| 四·事件驱动 | 系统任务→事件种子库 | ⭐必选 |
| 八·道具/能力进化 | 系统商城/能力升级路线 | ⭐必选 |
| 九·旁白解说 | 系统提示音/任务完成/成就解锁 | ⭐必选 |
| 五·NPC自主行动 | 后宫成员主动推进 | 推荐 |
| 十·多阶段开场白 | 不同进度存档点 | 推荐 |
| 十一·阶段行为特征库 | 每个女主的沦陷阶段 | 推荐 |

### 特殊条目设计

**系统人格条目**（常驻）：系统有自己的人格/吐槽风格（如"嘎嘎嘎"），是重要的氛围角色。必须单独建条目。

**系统提示格式条目**（常驻）：定义系统消息的输出格式：
```
【叮！xxx任务完成！奖励xxx点万恶值。】
【成就解锁：xxx，效果：xxx】
```

**能力/道具条目**（常驻）：把系统商城中购买过的能力和道具集中描述，作为AI使用指南。避免分散在各角色条目中。

### 状态栏设计要点

系统流的面板信息最丰富，需要展示：
- 主角核心属性（等级/数值/资源）
- 在场角色的当前状态/阶段
- 当前任务/活跃效果
- 时间/地点

```
<action_info>
| 【陈箜】体质:10级 | 神识:10级 | 万恶值:21200 | 透支:1000000 |
| 【陈珂】阶段:完全臣服 | 关系:妹妹→性奴 | 兄控值:MAX |
| 【刘梓莹】阶段:沦陷 | 沦陷值:100 | 当前:在男友身边偷发消息 |
| 【时间】周六下午3点 | 【地点】家中客厅 | 【在场】陈晴冰、陈珂 |
| 【活跃任务】征服钱薇(进行中) | 缩阳蔑(已习得) |
</action_info>
```

**特征**：男主是苦主/旁观者，核心是妻子/女友被他人征服。
**代表作**：示例游戏项目港区NTR、示例角色项目

| 九·旁白解说 | 苦主内心独白/旁白 |

## 原型三：征服者后宫（Conqueror Harem）

**特征**：{{user}} = 男主，主动征服女性建立后宫。可能含NTR元素（绿别人）但核心是后宫建设。
**代表作**：万恶后宫系统、dzmm校园精英学伴

### 推荐模板组合

| 模板 | 用途 |
|------|------|
| 一·状态栏 | 多角色状态追踪 |
| 二·好感度 | 每个女主的征服进度 |
| 五·NPC自主行动 | 后宫争风吃醋/主动献身 |
| 六·风险检测 | 被苦主/家人发现的风险 |
| 十·多阶段开场白 | 不同后宫规模的切入点 |

### {{user}}视角
{{user}} = 男主/征服者。所有女性角色由AI扮演。苦主角色也由AI扮演。

### 关键区别 vs 纯NTR
- 纯NTR：{{user}}是受害者视角，情感核心是"发现→痛苦→接受"
- 征服者后宫：{{user}}是加害者视角，情感核心是"猎取→调教→占有"
- 状态栏视角完全不同：NTR追踪"察觉度"，后宫追踪"征服进度"

## 原型四：禁忌/乱伦（Taboo/Incest）

**特征**：核心是家庭成员之间的禁忌关系，不涉及外部NTR。
**代表作**：抵受不住亲姐姐、示例角色项目

### 推荐模板组合

| 模板 | 用途 |
|------|------|
| 一·状态栏 | 家庭关系状态 |
| 二·好感度 | 从亲情到爱情的转变 |
| 五·NPC自主行动 | 家庭成员的暗中行动/偷跑 |
| 六·风险检测 | 被其他家人发现的风险 |
| 十一·阶段行为特征库 | "压抑→试探→突破→沉沦"阶段 |

## 子模式A：赌约/协议驱动型NTR（Wager-Driven NTR）

**特征**：剧情由**赌约、协议、契约**等约束性机制驱动，而非单纯的"被征服"。核心是"规则博弈"——双方在明确规则下竞争，违约有惩罚，惩罚可升级。
**代表作**：艳母的荒唐赌约（三次赌约+两次协议）

### 与普通NTR的关键区别

| 维度 | 普通NTR | 赌约驱动NTR |
|------|---------|------------|
| 驱动力 | 征服者的魅力/暴力/胁迫 | 规则+赌注+违约惩罚 |
| 女主心理 | "我被征服了" | "我输了/我违约了" |
| 控制链 | 征服→服从 | 赌约→协议→违约→升级协议 |
| {{user}}体验 | 无力/发现/痛苦 | 算计/偷窥/试图夺回规则主导权 |

### 机制分层（必须分别编码）

1. **赌约层**（为什么开始）：双方打赌，赌注驱动剧情转折
2. **协议层**（怎么控制）：正式约束性文件，含条款/违约惩罚/执行条件
3. **升级层**（控制链深化）：违约→惩罚翻倍→新协议→更严酷条件

⚠️ **铁律**：赌约和协议是**不同控制层级**，计划书中必须分别做结构化编码，不能合并为一条。用户会主动追问"协议呢"——漏掉任何一层都是交付缺陷。

### 推荐模板组合

在原型二（纯NTR）基础上，额外必选：
- 模板四·事件驱动：赌约/协议事件种子库（enabled=false）
- 模板七·心理操控：赌约的道德绑架+协议的胁迫循环
- 模板九·旁白解说：赌约规则解释、协议条款说明、违约风险提示
- 模板十七·反顺从：赌约有规则，玩家不能口胡

## 原型选择决策树

```
小说有系统/面板/数值？ → 原型一（系统流）
  ↓ 否
{{user}}是被绿的一方？ → 原型二（纯NTR）
  ↓ 否
{{user}}主动征服多个女性？ → 原型三（征服者后宫）
  ↓ 否
核心是家庭禁忌关系？ → 原型四（禁忌/乱伦）
  ↓ 否
→ 混合原型，按比例选择主要+次要模板
```

### 混合原型示例

**万恶后宫系统** = 原型一（系统流）+ 原型三（征服者后宫）+ 部分原型四（母子/兄妹）
→ 以系统流为基础，叠加后宫管理模板，加入家庭风险检测

**艳母的荒唐赌约** = 原型二（纯NTR）+ 原型四（禁忌母子）
→ 三次赌约+两次协议为A级核心驱动机制。{{user}}=刘宇（苦主/操纵者）。排除配角后聚焦核心五人。
→ 关键：赌约和协议是**不同控制层级**，必须分别结构化编码（条款正文/违约条件/惩罚升级），不能合并为一条。
→ 协议控制链：赌约引发事件→协议锁定结果→违约惩罚→升级协议。
→ 覆盖模板：一/二/四/五/六/七/九/十/十一/十二/十三/十四/十五/十六/十七/十八/十九（16个P0）。
→ 规划书路径：`酒馆/小说资源/4/艳母的荒唐赌约/规划书_v1.md`

## {{user}}视角决策框架

| 小说类型 | 推荐{{user}} | 理由 |
|----------|-------------|------|
| 系统/后宫流 | 男主/征服者 | 系统绑定在男主身上，用户需要控制能力使用 |
| 纯NTR | 苦主/被绿者 | 情感体验在"发现真相"的痛苦 |
| 征服者视角NTR | 征服者 | 用户享受"绿别人"的快感 |
| 禁忌/乱伦 | 家庭成员之一 | 根据核心关系决定 |
| 多视角群像 | 上帝视角 | 用户不扮演任何角色，AI扮演所有人 |

**决策关键**：系统/能力绑定在谁身上？→ {{user}} = 那个人
