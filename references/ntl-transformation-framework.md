# NTR→NTL 视角转换框架

## 何时使用
已有NTR苦主视角角色卡，需要制作NTL（Netorare-to-Love / 夺回）变体版本。玩家目标从"承受被绿"变为"夺回所爱之人"。

## 社区需求采集
NTL版本通常由玩家反馈驱动。常见诉求：
- "如果能一个user把四女都收就好了"
- "有纯爱路线或者NTL视角就好了"
- "这个设定很好，只是NTR玩的很难受"
- "喜欢击败NTR角色，把自己爱的人从堕落边缘夺回来"

**采集渠道**：Discord评论、B站弹幕/评论、QQ群截图。用户提供的截图需要视觉分析提取具体反馈。

## 三大设计轴

### 轴1：User强化（不是无双）
**核心**：让user有夺回的能力，但不能碾压。

设计原则：
- 预知天赋/特殊能力保留但增加**代价**（精神力消耗、冷却时间、预知反噬）
- 新增强化成长线（通过剧情解锁能力，而非开局满级）
- 给user独特的"反制工具"（贞操锁施加给NTR角色、雌堕药剂、记忆唤醒道具等）

**禁忌**：不能把user改成无敌战神。NTL的乐趣在于"有希望但需要努力"。

**预知天赋三阶段解锁模型（实战验证）：**

| 阶段 | 触发条件 | 能力 | 代价 |
|------|---------|------|------|
| Phase 1·碎片预知 | 随机触发（同原版） | 看到模糊NTR画面 | 精神疲劳（头痛/眩晕） |
| Phase 2·定向预知 | 主动选择不自欺 | 指定目标/地点预知，画面清晰 | 精神力大量消耗+短暂失去意识 |
| Phase 3·命运干涉 | 第一次成功阻止NTR | 预知未来3步+临时提升战力30秒 | 预知反噬（昏迷/流鼻血/记忆碎片化） |

**user性格四阶段（替代原版自欺循环）：**
- Phase 1（觉醒前）：同原版自欺，但内心有不安的火种
- Phase 2（觉醒期）：自欺崩塌，愤怒涌上来
- Phase 3（夺回期）：冷静、有计划、有担当
- Phase 4（唤醒期）：温柔而坚定

**屈辱→愤怒转化机制（替代原版受虐倾向）：**
原版：屈辱度→自欺→接受→兴奋（受虐）
NTL版：屈辱度→不甘→愤怒→觉醒→夺回
每10点屈辱度转化为1点愤怒值，愤怒值提升战力但降低判断力。

### 轴2：苦主体验系统反转
原版苦主体验系统施加给user，NTL版反转施加对象：

| 原版（施加给user/女主） | NTL版（施加给NTR角色） |
|---|---|
| 女主被NTR角色侵犯 | NTR角色被user用贞操锁控制 |
| 女主堕落加深 | NTR角色被雌堕药剂削弱 |
| user被迫观看 | user主动干预并反击 |
| 女主身体背叛 | NTR角色身体被改造 |

**反转道具系统（实战验证）：**

| 道具 | 效果 | NTR角色反应 |
|------|------|------------|
| 贞操锁 | 控制力-30 | "伯里哥哥……我错了……"哭着求饶 |
| 雌堕药剂 | 控制力-50 | 声音变尖、行为娇羞、手下目瞪口呆 |
| 狗链/项圈 | 控制力-20 | 地位反转，跪舔 |
| 反转法杖 | 控制力-60 | 直接控制目标行为 |
| 催眠术 | 控制力-40 | 目标被催眠 |

**限制**：每NTR角色同时1种道具效果，有持续时间(3-10轮)，过度使用触发"双败结局"。

### 轴3：挑战性保留（NTL最核心）
**绝对不能让夺回太容易。**

**三层叠加阻力模型（实战验证）：**

**第一层·NTR角色强大（物理阻力）：**
- 法杖系NTR：被动控制场，范围内女性自动受控。对策：先偷/破坏法杖
- 暴力系NTR：地下势力网，打手众多。对策：收集情报+逐个击破
- 权力系NTR：合法抓人/征税/定罪。对策：找到把柄/寻求外部势力
- 军事系NTR：正面打不过。对策：智取或寻盟友

**第二层·女主堕落深（心理阻力）：**
- 异常期：女主隐瞒+否认，user不确定真相
- 沉沦期：女主享受NTR，对user不耐烦，唤醒成功率大幅降低
- 臣服期：女主主动为NTR辩护甚至敌视user，必须先削弱NTR控制力

**第三层·女主对user爱得不够深（感情阻力）——关键设计：**
每条线的唤醒难度不同（用★标注）：

| 女主 | 初始感情 | 唤醒难度 | 核心障碍 |
|------|---------|---------|---------|
| 师傅型 | 师徒之情（非爱情） | ★★★★★ | 需突破师徒关系界限 |
| 大姐姐型 | 暗恋（不承认） | ★★★★ | 需打破骄傲 |
| 义姐型 | 保护欲 | ★★★ | 需角色反转（user保护她） |
| 妹妹型 | 占有欲（雌小鬼式） | ★★ | 需让她吃醋+正视感情 |

## 堕落-唤醒双轨系统（实战版）

### 唤醒值（Awakening）系统
每个女主独立的**隐藏属性**（0-100），user无法直接看到数值。

| 唤醒值 | 状态 | 表现 |
|--------|------|------|
| 0-20 | 沉睡 | 完全被NTR控制，对user冷漠/敌意 |
| 21-40 | 微醒 | 偶尔犹豫，NTR一个命令就压回去 |
| 41-60 | 半醒 | 意识到被控制但身体/心理无法挣脱 |
| 61-80 | 觉醒 | 主动抵抗NTR，但堕落值会反弹 |
| 81-100 | 完全唤醒 | 摆脱控制，回到user身边，**保留NTR记忆** |

### 唤醒手段（各有成功率和风险）

| 手段 | 成功率 | 风险 | 适用阶段 |
|------|--------|------|----------|
| 回忆唤醒 | 30-50% | 失败加深堕落 | 异常/沉沦 |
| 预知唤醒 | 40-60% | 精神力消耗+反噬 | 沉沦/臣服 |
| 战斗夺回 | 50-70% | 受伤+NTR报复 | 任何 |
| 牺牲唤醒 | 60-80% | 永久伤害 | 臣服 |
| 反向控制 | 70-90% | 道德风险+女主事后怨恨 | 臣服 |

### 裂隙机制（Crack）
每个堕落阶段都有"裂隙"——真实自我残留：
- **异常期裂隙**：眼神闪躲、欲言又止（user在场时）
- **沉沦期裂隙**：关键时刻动摇、身体抗拒
- **臣服期裂隙**：高潮时叫错名字、梦境呼唤

裂隙是NTL版的"锚点"——证明女主不是真的爱NTR角色。user的任务是找到并撬开裂隙。

### 堕落反弹机制（关键！）
唤醒不是单向的——NTR角色会反击：
- 法杖系NTR：强制控制 → 唤醒值-10~-20
- 暴力系NTR：暴力威胁+征服 → 唤醒值-5~-15
- 金钱系NTR：诱惑+权力施压 → 唤醒值-5~-10
- 文化系NTR：征服文化+暴力 → 唤醒值-8~-15

**设计意图**：你唤醒了她，但NTR一个回合就能推回去。必须**同时削弱NTR控制力 + 持续唤醒**才能成功。

## 唤醒场景升级链（替代原版NTR升级链）

| Level | 名称 | 表现 |
|-------|------|------|
| 1 | 试探接近 | user与女主正常对话→女主冷漠/回避 |
| 2 | 回忆唤醒 | 提起过去的回忆→女主短暂动摇 |
| 3 | 裂隙扩大 | 女主在NTR场景中抗拒→被NTR强行压制 |
| 4 | 决裂时刻 | 女主主动向user求助→NTR发现并报复 |
| 5 | 最终唤醒 | user付出极大代价→女主挣脱控制 |
| 6 | 回归与创伤 | 女主回到user但有PTSD→需长期治愈 |

## 开场白调整
NTL版开场白与NTR版的关键差异：
- **视角**：从"无力旁观/被迫承受"变为"有目标但困难重重"
- **基调**：从绝望/屈辱变为"挑战/希望但路途艰难"
- **首幕**：展示user获得能力/工具的契机，同时展示当前困境（女主堕落状态 + NTR角色嚣张）
- **必须同时建立希望和威胁**
- **觉醒时刻**：必须有一个明确的"我不再自欺了"的转折点
- **信息优势**：展示预知天赋的第一次主动使用

## 四结局分支设计

| 结局 | 触发条件 | 场景 |
|------|---------|------|
| Golden End·完美夺回 | 4女唤醒值≥80，所有NTR被击败 | 反向婚礼，真心幸福 |
| Normal End·部分夺回 | 1-3女唤醒值≥60 | 被唤醒的回来，其余留NTR |
| Bad End·苦主终局 | 所有女臣服，未唤醒任何一个 | 同原版屈辱婚礼 |
| True End·双败 | 使用苦主体验道具过多 | "你和他们有什么区别？" |

## NTR角色弱点系统（NTL必备）

每个NTR角色必须有弱点，否则NTL无从下手：
- **法杖系弱点**：需持续握持（被打落控制力减半）；小孩体力差；有使用范围
- **暴力系弱点**：势力被调查时混乱；血脉有暴走风险
- **权力系弱点**：贪财怕上级调查；父子关系可离间；府邸有密道
- **军事系弱点**：边境战事吸走兵力；内部权力斗争；怕火

## NPC被削弱/反转机制

每个NTR角色有"控制力"值(0-100)：
- 控制力<50：NTR开始慌张，行动更谨慎
- 控制力<20：失去对女主的控制，女主进入可唤醒状态
- 控制力=0：彻底失败，可选择施加苦主体验

## 世界书条目修改清单

从NTR版转NTL版时需要修改的条目类型：

**必须修改：**
1. **全局规则条目**：移除"禁止user变强"，加入NTL核心规则（有代价的觉醒、有策略的夺回）
2. **User设定条目**：完全重写（觉醒者档案、三阶段预知天赋、四阶段性格）
3. **苦主体验条目**：改为双模式（苦主被动+夺回主动），可反转施加给NTR
4. **防拒绝条目**：保留NSFW规则，增加"夺回/唤醒场景同等描写待遇"
5. **NPC系统条目**：增加弱点暴露机制+被反转后行为
6. **剧情推进条目**：增加NTL路线推进阶段+唤醒升级链+四结局分支
7. **状态栏条目**：增加唤醒值、控制力、NTR状态、愤怒值、精神力
8. **开场白**：全部重写（觉醒时刻+信息优势+建立威胁）

**必须新增：**
9. **唤醒系统规则条目**（常驻）：唤醒值阶段、唤醒手段、反弹机制、裂隙机制
10. **NTL版状态栏条目**（常驻）：替代原版，增加NTL数据字段
11. **夺回路线剧情树条目**（选择性）：各女主的夺回阶段和分支点
12. **反转道具系统条目**（选择性）：可用道具、效果、限制、剧情亮点
13. **NTL随机事件条目**（常驻）：1D8骰子表+夺回事件库
14. **结局分支条目**（选择性）：四结局触发条件和场景
15. **NTL对话库条目**（选择性）：替代原版自欺台词

## 实战补充：变体卡制作中的额外检查项（2026-07-11验证）

制作NTL变体卡时，除了上述条目清单，还必须处理以下问题：

### 旧条目冲突处理
- **状态栏冲突**：NTL版新状态栏(ID34)和原版状态栏(ID2)会同时激活 → 必须禁用原版（`enabled=false`）
- **NTR描写库上下文**：原版苦主视角描写库(ID28)在NTL版中仍有价值（苦主模式被动触发时参考），但需在开头添加NTL上下文说明，避免AI混淆
- **BAD END条目**：原版BAD END路线(ID32)在NTL版中保留，作为Bad End结局的详细描写参考

### alternate_greetings必须全部改写
变体卡不能直接沿用原版开场白。每条greeting都需检查：
- 原版greeting中的**自欺结尾** → NTL版改为**觉醒+行动选择**
- 原版greeting中的**废物自我认知** → NTL版改为**不甘+愤怒+决心**
- 原版greeting中的**屈辱婚礼** → NTL版改为**BAD END预览+旁白提示可改写**
- 改写后同步到顶层和data层

**实战案例**（示例角色项目卡alt[4]改写）：
```
原版结尾：你咬着嘴唇，贞操锁里漏出了精液。这就是你——废物伯里——的结婚仪式。
NTL版结尾：【旁白：这是BAD END预览。如果你不去夺回——这就是最终结局。但你还有选择。】
           你从噩梦中惊醒。冷汗浸湿了你的衣服。
           "我要把她们夺回来。所有四个。"
```

### NTL版特有审计项（脚本审查时追加检查）
1. **状态栏控制者覆盖度**：NTL版状态栏中每个女主的"控制者"选项必须覆盖NTR矩阵中所有目标（常见遗漏：练武场壮汉、肥猪领主、黑兽人）
2. **唤醒阶段对齐**：ID33唤醒系统定义的5个阶段（沉睡/微醒/半醒/觉醒/完全唤醒）必须在ID34状态栏中完全一致
3. **道具限制与结局触发对齐**：ID36道具限制次数（如"累计≥5次触发双败"）必须与ID38结局触发条件一致
4. **伯里设定一致性**：ID0全局规则、ID4苦主体验、ID16伯里档案、ID39对话库中对预知天赋阶段、愤怒转化机制、性格阶段的描述必须一致

## 注意事项
- NTL版是**独立卡**，不是NTR版的补丁。玩家可以同时保留两个版本
- 保留原版的角色关系设定和世界观，只改变user的定位和系统机制
- NTR角色不能削弱到可笑的程度——"旗鼓相当的对手"比"碾压弱鸡"有趣得多
- 社区反馈是需求来源，但最终设计权在卡作者（你）手中
- **NTR记忆保留**：女主被唤醒后保留NTR记忆——创伤记忆是后续剧情张力来源
- **NTR人格保留**：NTR角色被反转后保留人格——他们被施加苦主体验后的反应才是剧情亮点（哭着求饶/震惊/愤怒）
- **"废物"一词在NTL版中的使用**：NTL版中仍可出现"废物"，但必须在正面语境（如"那不是废物的眼神"、BAD END预览、NTR角色的蔑称），不能是user的自我认知
